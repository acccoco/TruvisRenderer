## 发现与实施范围

**P1，已确认：** traced surface 的 `origin_normal` 是几何法线，但 surface key 仅保存
`forward_normal`。`surface_from_key` 用后者重建 origin_normal，改变 ReSTIR 重连时
visibility offset 的方向；normal map 或平滑法线与三角形法线不一致时可触发。
不是整个 BRDF 半球策略的修复，也不证明 GPU 画面已经出现何种伪影。

参考 `resources.toml` 的 RTXDI v3.0.0，父仓库实际
`274141af082050c9d0ad6e01a2e591d0d66b7955`；Rtxdi 子库实际
`a14e079c727ed8c4fd3173bd2aea8244c9d9f6d6`，与父仓库 gitlink 一致。
FullSample `Shaders/LightingPasses/RtxdiApplicationBridge/RAB_Surface.hlsli` 分开读取
normal / geoNormal；本项目保留自己的 RGBA32F key 与射线 offset，不移植其压缩 GBuffer
或半球裁剪策略。粗糙 surface 当前 F0 仍由 .04 与 metallic 混合，key 的占位 IOR=1
不能作为当前粗糙 F0 错误的证据。

## 架构预检

RestirDiTargets 继续拥有按 FIF 轮转的 image，新增 surface D 保存几何法线 xyz，w=0。
RT pass 原 push set 已有 32 个 descriptor；surface current/history 共八张图像改用
独立普通 descriptor set，每 FIF 一份，槽位重用前由 Runtime timeline 保证完成。
pass 拥有 layout/pool/sets，图像仍由 Renderer subsystem 在 resize/shutdown 安全点释放。
复用原有 descriptor wrapper、构造回滚、RenderGraph import 和 phase barrier；不新建资源框架。
变更只在 Renderer 内部，无 Engine 反向依赖；不改变线程、pass 顺序、reservoir 历史来源、
shader buffer record 布局或 public 材质 API。descriptor set ABI 与图像数量会改变。
活跃契约同步到 sampling design 和相关模块 README。

## 实现与验证

修复位于本报告所在提交。`surface_key_from_hit`、store/clear、current/history load 与
`surface_from_key` 已贯通独立的 origin_normal；几何法线保持 traced hit 的原始单位 float
分量，避免再次归一化改变 ULP offset 步长。两条 load 共用 `unpack_surface_key`，在
normalize 前拒绝非有限位置/材质/法线/深度、非正深度、零法线及法线平方和溢出。
没有新增独立 sampler、compat fallback 或法线压缩设施。

图像 D 已接入创建、FIF 选择、导入、graph access、phase barrier、view/descriptor 和销毁遍历。
普通 surface set 的 pool/layout/分配前缀均加入 RT pass 的既有构造回收；每帧借用设备仅用于
写 descriptor，不扩展 Engine record context，也不在录制时分配图像。Runtime `begin_frame`
的 FIF timeline wait 先于 Renderer 构图与 RT 录制，同一 pass 一次录制所有 phase。
此处核对的是当前单次录制调用链，不承诺同一 FIF 槽位允许并发/多次覆盖 descriptor。

- 临时夹具抽取修改前/后的真实 key、store/load、重建函数与当前 offset，C++ float 执行，
  用内存 image mock 替代 GPU storage。8 种几何法线 × 5 种着色法线 × 3 个位置尺度 ×
  4 个方向 × current/history，共 960 次往返；offset 与 traced 输入不一致的次数
  **864 → 0**，材质与着色法线保持预期。两条 load 各覆盖 14 个非法输入，接受计数
  **22 → 0**；空 key 的非有限 normal **1 → 0**。O0/O2 结果相同。
- `just shader`：24 编译、7 复用，两个 binding crate 通过。
- `cargo check -p renderer-rendering` 与 `cargo build -p renderer-rendering` 均通过，覆盖 render-pass 与 rendering 消费方。
- Realtime/Offline raygen 通过 `spirv-val --uniform-buffer-standard-layout`；反汇编核对
  surface set=5、binding=0..7 与 Rust descriptor 声明一一对应；生成 binding 的
  SURFACE_SET_NUM=5。push set 从 32 降为 26 个 descriptor，SHARC 仍为 set=4。
- 本机 `vulkaninfo`：RTX 4060，maxBoundDescriptorSets=32、maxPushDescriptors=32；
  新布局总共六个 set，构造前显式检查 set 上限。新增内存为每 FIF 16 字节/像素。

证据在 `.temp/code-design/B19-a/`，未新增永久测试。夹具不执行 Vulkan image load/store、
RT traversal 或 GPU FTZ；未做真实 normal-map 场景、resize/失败注入、图像/性能验收。
shader/Rust 构建与静态生命周期接线不能替代这些验证。
