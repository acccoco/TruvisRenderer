## 组合构造

**P1，已修复：后续构造失败遗漏先前成功 owner。** 原先以 Self 字段表达式依次创建
共享 queue、texture、sky、mesh、material；后项失败时 Rust Drop 不能替代显式 GPU
释放，sky worker 也没有得到 stop/join。现在分阶段保存已成功返回的 owner，全部成功
才交付 RenderAssetSystem。失败先停止 worker，再关闭空的共享 queue，继续回收已完成
的 mesh/sky/texture，最后传播原始构造错误；清理诊断不能覆盖该错误或跳过剩余回收。

构造期尚未调用 sync，两条上传队列均为空，已成功返回的 fallback 已完成同步初始化。
这是本次回滚可安全进行的依据；不能将它套用于已提交场景资源，也不接管尚未成功返回
的叶子 owner。同步 fallback 构造中的未知提交及 native 退场仍遵守 B10-d3a/B05-c4 边界。

复用各 owner 的 new/destroy/stop 方法，不增加通用析构器、恢复状态机或兼容路径。
Option 仅存在于构造局部，成功对象仍持有完整必需字段；公共 API、shader ABI 和正常
同步发布路径不变。

## 组合关闭

**P1，已修复：已释放 owner 的诊断异常中断整个集合收尾。** 原关闭流程先 material，
再 worker/queue/sky/texture/mesh；前者异常会阻断后者。现在先 stop worker，再关闭
共享 queue。queue 的只读 is_shutdown 只用于区分等待失败与回收已完成后的诊断失败，
不开放上传重试。确认 queue 已关闭后，material/sky/texture/mesh 各自完成收尾，最后
传播保留的首个异常；Runtime 必须已经停止消费者并等待已发布资源的 graphics 使用结束。

共享 queue 等待失败时，关闭错误优先于此前 worker 诊断传播，不进入后续 GPU owner
释放。没有吞掉 timeout/device error、没有强行设置 destroyed，也没有把 CPU worker
停止等同于 GPU 完成。mesh 使用独立 graphics queue，其内部等待门槛继续由 GpuMeshStore
负责，未将不同队列的完成状态合成单一标志。

最终 22 类场景在新旧版本、两种断言配置下共 **88 次进程运行**符合预期：

- 正常关闭确认 stop worker→共享 queue 完成→各发布资源 owner，全部模拟资源释放。
- worker、queue semaphore、material、sky、texture、mesh 单项与组合释放诊断异常，
  新版均完成其余已知安全 owner 回收；旧版除最后一项外存在剩余资源。
- 使用实际 queue 提交 texture，完成后注入 staging/image/semaphore 释放异常；queue
  仍标记完成，组合层继续回收。构造期空 queue 不依赖 GPU 等待或 CPU scene readiness。
- 实际共享 queue wait 失败时，pending、同步资源仍在，后续 material/sky/texture/mesh
  destroy 未调用；同时注入 worker 诊断时仍进入 queue wait 并优先传播等待失败。
- mesh 等待失败按其既有约束保留 mesh，其他已经过安全门槛的 owner 已完成回收；
  这项使用 mesh 替身，实际 mesh 等待边界的证据仍见 B10-b1/B10-b3。

最终 Runtime/app 的 `cargo check --offline --locked` 与空白检查通过，无新增警告。
未运行真实 GPU、图像回归或完整构建。事件替身不证明驱动失败后的释放合法性、真实
跨 queue 内存可见性或完整 Runtime unwind 安全。

## 交接

按值消费 self 的销毁 API 仍不能在等待失败后把整个组合 owner 返回给调用方；外层
展开还可能触发未关闭 queue/sky 的 debug Drop 断言。这是已有失败退场缺口，本批只
保证不越过等待失败继续显式释放，不宣称 pending 可跨 destroy 调用恢复或全程无遗漏。
已发布资源的安全点由 RenderRuntime::destroy 开头的 Gfx 等待提供；更外层提前失败、
通知交付及组合生命周期继续 B11/B12，最终统一退场策略仅在 B26/B27 提方案。

现有 owner 各有独立完成条件，保留显式分阶段构造与销毁；没有证据支持为这些局部路径
引入通用 teardown 注册表或合并 worker/transfer/mesh 队列。
