# B08-c2b：glTF 几何生成与着色属性语义

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准：`refactor` 的 `72519309`。读取 Reader、SubmeshData、GpuMeshStore 的原样上传路径，
以及 Engine MaterialAccess 和 raster Phong 的 normal/tangent 消费。资产层拥有格式转录和
CPU 数据；实际法线贴图解码仍由既有 shader 完成，不在导入器复制材质算法。

## 发现与局部方案

- **P1：缺失法线时错误平滑共享顶点。** 原 generate_normals 跨面累积，硬边模型变为
  平滑表面，且缺少 NORMAL 时仍保留 TANGENT。现在按三角形角点展开 positions/全部 UV，
  为每面写相同法线并清零切线；保持三角形顺序、绕序、材质、UV 集身份和 primitive 数量。
- **P2：面积计算依赖模型尺度。** 原 f32 叉积及 EPSILON 阈值会把小面变成 +Y；大坐标
  可能溢出为零/非有限法线或意外回退 +Y。现在用 f64 计算有限 f32 顶点的差、叉积和单位化，
  仅精确零面积面沿用 +Y 占位。没有删除退化面或改变 primitive 编号；该策略不赋予零面积面
  物理法线，也不保证 GPU 对极端坐标的数值稳定性。
- **P2：输入 NORMAL/TANGENT 语义只检查部分条件，已修复。** SubmeshData
  只要求有限、法线非零；非单位法线、零/非单位切线方向及非 ±1 handedness 可进入 shader。
  现在在 glTF Reader 校验实际消费的 authored frame，保持程序化 mesh/Assimp 公共契约不变。
  复用锁定 glam 0.22.0 的 is_normalized（长度平方与 1 的偏差不超过 1e-4），w 须严格 ±1。
  合法输入原值保留，不静默归一化；不存在的切线可保留零标记。

依据：[glTF Geometry](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#meshes)
（页面 2.0.1，commit 8e798b02d254cea97659a333cfcb20875b62bdd4）明确规定缺失 NORMAL
生成 flat normals 并忽略已有 TANGENT。工程参照为本地 Bevy v0.20.0-rc.1，commit
`1b1f3ec1bec87386d7c19bda7d7870d4e18235c5` 的 `bevy_gltf/src/loader/mod.rs`：先
duplicate_vertices 再 compute_flat_normals。只采用局部展开方式，不引入其 mesh 框架。

## 架构预检与实现边界

改动限于 GltfSceneReader 私有 impl；复用 SubmeshData::validate、现有 glTF accessors
和 glam 向量。不新增依赖、公共字段、shader/FFI/ABI、线程或资源 owner。初次构造中缺失
法线的临时 +Y 数组仅用于复用输入检查，发布前必须完成 flat 展开并再次 validate；任何错误
只返回失败 completion。展开前检查顶点和 UV 总数的 u32 上界，不承诺 OOM 可恢复。

缺失 NORMAL 时不读取 TANGENT 数值；B08-c2a 的声明布局检查仍执行。缺失 tangent 保留零
标记，下游 `MaterialAccess::tangent_from_derivatives` 在 RT 使用三角形差分、raster 使用
屏幕导数重建。这里没有 CPU MikkTSpace；不能宣称与烘焙工具的平滑切线基完全一致。

## 验证与交接

`.temp/code-design/B08-c2b/fixtures.py` 与 `run.py` 使用真实 glTF 文件、locked gltf/glam
和完整 Reader/handle/material texture，只替代 request/result 外壳。第一项修复的 39 个
新旧案例在夹具断言/溢出检查同开、同关配置下通过；第二项完成后增加非轴向面数值对照，
共 **42 个新旧案例**在两种配置下通过，方向/handedness 病例已切换为新版拒绝期望。
未将全部依赖重编为 Release。

验证包括共享硬边、相反绕序、indexed/nonindexed、多套 UV 与 normal UV 选择、丢弃
未引用顶点、缺法线时丢弃 authored/NaN tangent、从 1e-40 到 1e38 的尺度、溢出坐标差、
重复索引/共线/混合退化面，以及有法线时原布局和值保留。非法索引、NaN 顶点和不完整
三角列表继续拒绝。输出 positions/normals/indices/UV/tangent 有直接断言；旧版平滑法线、
小面/溢出面回退 +Y、缺法线仍保留 tangent 也有基准断言。新版本拒绝非单位 normal、
零/非单位 tangent.xyz、w=0/±2/非有限，保留正常 ±1 sign 与容限内浮点误差。

两个实现阶段的 `cargo build --offline --locked -p truvis-asset` 与
`cargo check --offline --locked -p truvis-world` 均通过。没有新增仓库单元测试，未验证 GPU。
本批两个提交：`03fbf243` 修复缺失法线；**本报告所在提交**校验输入 frame 并完成审阅交接。
代码和相关说明按行为一并提交，空白检查通过。

剩余风险：展开提高 CPU/GPU 顶点占用，资源预算交 B13/B27；MikkTSpace、authored tangent
与 texture transform/动态切换 UV 的组合需由材质子批及 B15 核对，不在本批改 shader。
本批约定范围已完成；不要求 tangent 与 normal 严格正交，仍由 shader 投影后判断退化；
同面不同 tangent.w 的未定义基不在入口自动重写。完整材质模型/画面与极端尺度 GPU 支持
没有验收，也未声称完整 glTF 合规。
