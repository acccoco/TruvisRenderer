## 局部修复

**P2：固定余弦分母 floor 压低窄锥亮度，等角未形成硬边界。** CPU 明确接受
`0 <= inner <= outer <= f32 π`，包括 0 与 inner==outer；原 shader 用
`max(cos(inner)-cos(outer),1e-5)` 作分母，导致窄锥内侧也达不到完整 radiance。
相近余弦相减、叉积乘积相减，以及接近 π 的角度舍入进一步丢失有效过渡。

修复仍属于 RtDirectLighting::spot_cone_falloff：

- 内侧返回 1、外侧返回 0，等角为包含边界的硬锥。非法角度不再通过 min/max 静默交换。
- 保留原来的余弦线性模型，用 cos 差的正弦乘积恒等式，分别求比避免先相乘下溢。
  展开平均角的 sin，避免接近 π 时平均角先舍入到端点；没有改成按角度线性或 SmoothStep。
- 从最近轴端求 atan2；背向用 f32 π 的高低位差还原剩余角。叉积以 FMA 补偿乘积误差，
  length 先缩放避免平方下溢；利用 atan2 比值的尺度不变性，去掉冗余方向归一化。
- 新采样和重建继续共用同一衰减，只改变 radiance，球面 proposal/class PDF 不变；
  零贡献拒绝不重抽样。无 ABI、资源 owner、生命周期、依赖方向、线程或 pass 顺序变化。

核对本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（resources.toml master）
`lights.cpp::SpotLight::I` 与 `util/math.h::SmoothStep` 的区间及等角处理，
`DifferenceOfProducts` 的 FMA 补偿。PBRT 使用 SmoothStep 与 delta-position intensity；
本项目保持球面 radiance 和原有余弦线性衰减，只借鉴边界处理及数值方法。

## 验证

`.temp/code-design/B18-b3c/check-spot.py` 抽取实际函数，以 C++ float O0/O2、关闭隐式
contraction、显式 std::fma 执行。向量类型/数学内建为 CPU 适配，GPU table 无参与。
参照以 long double 对同一 f32 输入向量计算真实夹角，再计算并 clamp 原余弦线性模型，
用正弦恒等式避免参照自身在窄锥下相减失真；MSVC ABI 下 long double 不保证超过 double。
不是将已舍入的 shader atan2 输出作为参照。

普通与窄锥集合含两个方向（Z 轴和归一化 (1,2,3)）、每过渡区 129 个角度点；
外角从 2e-7 到 f32 π，包含 0 内角、前向窄锥、背向 1e-5/1e-6 附近过渡。
另有轴向 1e-10/1e-20/1e-30 的 15 组压力输入，及 1 rad 处一个 float 间隔的 258 组。

| 集合 | 组数 | 原绝对误差 >1e-3 | 修复后 >1e-3 | 修复后最大绝对误差 |
|---|---:|---:|---:|---:|
| 普通及较宽过渡 | 1290 | 176 | 0 | 4.35e-7 |
| 前向窄锥，轴向 | 387 | 384 | 0 | 2.09e-7 |
| 前向窄锥，斜向 | 387 | 385 | 0 | 2.85e-7 |
| 背向窄过渡 | 516 | 455 | 0 | 3.73e-7 |
| 极小轴向角 | 15 | 9 | 0 | 8.36e-8 |
| 单个 float 间隔宽度 | 258 | 246 | 242 | 0.59922 |

O0/O2 结果一致；所有结果有限且在 [0,1]。硬锥轴内/轴外、0/π 端点对照错误从 4 降至 0，
四个窄锥内侧平台错误从 3 降至 0。负角、逆序、Inf/NaN 内角、零方向输入拒绝通过。
这不代表全部非法 GPU record 或任意浮点方向组合都已枚举。

`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
通过 `spirv-val --uniform-buffer-standard-layout`，反汇编确认补偿使用显式向量 Fma。
`git diff --check` 通过。未执行 GPU 图像、运行期性能、FTZ/denormal 或随机路径方差验证。
本函数较旧表达式增加三角函数和 FMA 成本，未测 GPU 开销。

## 剩余边界与交接

- 单 ULP 宽度明显受 atan2/dot/方向量化影响，不能宣称修复了任意窄的过渡。
  B18-d/B27 需统一评估输入域、最小可分辨过渡与更高精度计算取舍；本批不擅自收窄 CPU API。
- f32 π 略大于真实 π，原余弦线性模型在极背向有尾差；本批按其 clamp 语义保留，
  不能将小角数值改善解释为全支持域或完整照明模型证明。等角 π 的硬锥包含全部方向。
- 极小角仅验证轴向 CPU 算术；任意方向的输入量化、subnormal/FTZ 与 GPU intrinsic
  精度仍属 B18-d/B27。固定半径球面的支持域、analytic 无 BRDF-hit 竞争及 reservoir
  跨视点度量继续沿前批报告交 B19/B27，不在本批扩展模型。
