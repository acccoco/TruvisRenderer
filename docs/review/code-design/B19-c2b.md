## P1：历史校正使用了当前相机

`target_at_surface` 隐式使用当前 camera_pos，temporal 将历史 surface 传入时仍得到
当前观察方向。`RtMaterialSampler::eval_brdf/eval_brdf_pdf` 依赖 view_dir，且拒绝
着色半球之外的方向；因此历史 target 不只可能改变大小，还可能改变支持域。

反例：同一静态 surface 在旧观察方向下落在着色法线负半球，历史是 M=1 的零估计池；
相机移动后当前方向进入正半球，initial 有正 target T、weight W。旧校正把历史 target
也算成 T，分母成为 2T，使结果 W/2；按原历史方向求值为零，分母为 T，结果应为 W。
这不要求几何/材质改变；强 normal map 的着色半球边界可以与几何可见半球不同。
这是代码契约反例；本批尚未通过实际 GPU 场景复现画面。

修改归 RtRestirDI：target_at_surface 显式接收观察方向；当前竞争与 spatial 仍使用
当前相机，temporal 的历史校正使用 prev_view。当前 Camera::get_view_matrix 由
look_to_rh 产生刚体 view，方向按 `normalize(-R^T * (R*P+t))` 恢复。上一相机来自
PerFrameData.prev_view，Runtime 从 previous_view 上传，既有提交确认语义不变。
不新增 free helper、持久化字段、shared ABI 或依赖；不改变 owner、线程、pass 顺序、
资源生命周期、候选集合、RNG、winner 竞争或 M。未来非刚体 view 不在本恢复方式范围内。

参考版本：resources.toml RTXDI v3.0.0，父仓库
`274141af082050c9d0ad6e01a2e591d0d66b7955`，Rtxdi 子库
`a14e079c727ed8c4fd3173bd2aea8244c9d9f6d6`，与前批固定版本一致。
`DI/TemporalResampling.hlsli` 在 temporalSurface 上重算校正 target；FullSample 的
`LightingPasses/RtxdiApplicationBridge/RAB_Surface.hlsli::RAB_GetGBufferSurface`
明确按 previousFrame 选择 prevView，并从该 view 构建 surface.viewDir。
本项目仍以当前 TLAS 处理历史 visibility；修复观察方向不消除这一已知近似。

## 其余链路的审阅结果

| 入口 | 当前事实与处理 |
|---|---|
| RtRaygenView::motion_vector_pixels → GBuffer → reproject_history_pixel | 同一 object 点由前后 model 和无 jitter 相机投影，MV 是 previous-current；R32G32 保存，producer 拒绝非法投影并限制幅值到 65504。consumer 按 floor(pixel+MV+.5) 后加 offset，再作 bounds 检查。本批不另造 MV 通道 |
| find_temporal_history_coord | 中心一次、[-4,4] 随机 offset 最多八次，可能重复；遇到首个 surface-compatible 位置即停止，然后由 caller 检查池。与参考的先 surface 后 reservoir 边界一致；不增加按 winner 成败重试的条件化搜索 |
| surface_compatible | valid、normal dot>=.9、roughness 差<=.15、metallic 差<=.1、base color 最大差<=.18，再检查 3% 距离与 1% 位置阈值及米制 floor。temporal/spatial 共用；它们是启发式，不能宣称不同材质天生不能复用。相关误导注释已修正 |
| spatial_neighbor_offset / spatial_resample | 32 个不同的非零 offset，范围 ±3；随机 start 后取连续 8 或 16 个，单轮不会重复。边界跳过、兼容性、pool 接受与第二轮校正一致。当前读入图像在本 phase 不被修改，无需为正确性新增 cachedResult；是否缓存须另测性能 |
| 观察方向 / target 支持域 | 零 target 来源仍保留 M，但最终样本在该 source 上 target=0 时不进入 piSum；历史观察方向已修复。光源映射、当前 TLAS、有限距离等完整支持域继续 B19-c3 |

未把相似性阈值当成正确性证明，也不因 RTXDI 有更多参数就移植其 permutation、
checkerboard、clamp、Pairwise MIS 或搜索框架。暂无证据需要新抽象或重构两轮 spatial 遍历。

## 验证

临时文件统一在 `.temp/code-design/B19-c2b/`，没有新增永久测试。

- `check-view.py` 抽取真实 target_at_surface、temporal/spatial、reservoir、stream 与
  finalize/校正。用已知前后相机和三个刚体旋转独立恢复参考方向；mock target 为带半球
  支持域的观察方向函数，reconstruction、坐标/兼容性与 visibility 是 mock。三组当前
  相机、五组历史相机、两种 surface 位移、M=1/8/64、32 seeds、两个 phase 共 17,280 例。
  double 权重参考：错误权重 7,488 → 0，错误历史方向 7,488 → 0，winner/M 不符始终零；
  最大相对误差 2.11e-6，方向最大分量误差 5.97e-8，O0/O2 一致。并非实际 BRDF 图像验收。
- `check-selection.py` 抽取实际坐标计算、bounds、surface_compatible、搜索和 offset。
  6,561 个坐标、5,120 个搜索、64 组邻域及 14 个兼容性边界检查通过，O0/O2 一致。
  C++ 转录的构造参数初次出现 x/y RNG 求值顺序差异；夹具改用有序初始化明确顺序，
  不宣称该夹具证明 GPU 的逐项 RNG 序列。验证对象为舍入、边界、停止条件与邻域集合。
- B19-c2a 的 2,592 个采样组合、10,368 个复用组合和 152 项边界检查再次通过；仅适配
  target 新参数和局部矩阵/向量 mock，参考及断言未改变。
- `just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen 均通过
  `spirv-val --uniform-buffer-standard-layout`。未做 GPU 图像、动态场景、性能或 FTZ 验收。

## 留存限制与交接

重投影没有前后 jitter 差：由当前 primary ray 的位置可得，理想历史像素索引包含
`MV + current_jitter - previous_jitter`，现实现只有 MV。附近搜索可缓解但不保证命中；
PerFrameData 只有当前 jitter。B19-d 必须连同上一实际提交帧的 jitter/资源 owner 复核，
判断是否补齐局部状态链；不能从 frame_id 重新猜上一帧 jitter，也不能改变 DLSS 的 MV 语义。

depth 比较两次实际 hit_t，没有相机位移的 expected-depth 补偿。即使静态点完全重合，
相机径向移动超过当前距离约 3% 也会拒绝 history。这是已确认的保守筛选行为，画质/方差
影响未测，不直接判作能量错误或任意放宽阈值；后续策略评估要与位置、normal 和支持域联合。
