## 已确认问题与边界

**P1：origin_normal 被插值顶点法线冒充。** 其文档与 ray offset 要求几何法线，实际
`RtSurfaceEvaluator::evaluate` 却对 `interp_normal` 做 inverse transpose。介质出入依赖
dot(ray,origin_normal) 的符号，SHARC hash 与所有普通 visibility/continuation ray offset
也消费该值。三角形法线 (0,0,1)、插值法线 (0.8,0,0.6)、ray=(0.8,0,-0.6) 时，几何判断
进入、旧实现判断退出；平滑 shading 参数不应改变介质的内外侧。

最小修复：在现有 Engine GeometryEval 中生成 object-space 三角形法线；Renderer 继续使用
inverse transpose 变换它。负 determinant 时不额外翻转，保持原有 object-space 外侧约定；
不能直接取 world edges 的 cross，因为那会额外带上 determinant 符号。TLAS cull-disable、
坐标系、CPU/shared ABI 和线程/资源均不变。新方法不读取 Renderer，不新增自由函数。

着色法线的 faceforward 暂沿用原来的插值法线判面，以隔离本次几何归属修复；不能因此宣称
shading normal 已符合几何/观察半球。ReSTIR key 当前没有几何法线，重建时仍以 shading
normal 代替，此既有契约缺口必须在 B19 同步 surface key、历史、绑定与资源。

## 修复与验证

本报告所在提交完成上述修复。`GeometryEval::geometric_normal` 分别缩放两条边后求 cross，
再缩放 cross 后归一化，避免三角形尺度直接造成法线长度平方溢出/下溢。不引入固定面积
阈值，也不借退化 fallback 把插值法线再当成几何法线。它仍要求非退化三角形、有限非零边，
不证明任意有限顶点组合的差值、变换或 GPU 交点精度都安全。

参考核对：PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a` 的
`src/pbrt/shapes.h::Triangle` 分别维护几何与 shading normal，并处理 transform handedness；
项目保留自身 inverse-transpose 的 object-space 外侧约定，不复制另一套 reverseOrientation API。
RTXGI v2.7.0 本地 `19b9be9e58ce2bbb6470b9444fa87e93a2dc4c4e` 的
Sharc 子模块固定且实际为 `0b9f58bbc8c41736042d4da964830a247e424a00`，
`Libraries/Sharc/include/SharcCommon.h::SharcHitData` 推荐 world-space geometry normal。
当前 `RtSharc::make_hit_data` 与 debug hash 都读取 origin_normal，本修复使 trace 输入与该约定一致。

`.temp/code-design/B17-c2a/check-normal.py` 抽取真实 GeometryEval 方法、修改前后的世界法线
代码段和 offset_ray_origin；C++ float 执行，inverse matrix/参考法线由 NumPy double 对照。
提供 mock geometry/instance，不执行 RT traversal、GPU 或材质贴图采样。

- 160 组非退化输入覆盖平面/斜面/极薄三角形，1e-20/1/1e20 尺度，单位、非均匀缩放、
  两种负 determinant 与 shear 变换，平坦/倾斜顶点法线，进入/退出方向。
  极薄形状乘最小尺度后在输入 float32 中已成为零面积的一组不满足方法前置，明确排除。
- 基准中 80 组几何法线不符、40 组介质侧判断错误、40 组 offset 推到真实平面的错误侧；
  修改后以上计数均为零，法线最大向量误差 8.46e-8。offset 使用原点附近的真实算法分支，
  不由此证明所有世界位置的 ULP 偏移都正确。
- 160 组 shading normal 输出与基准完全一致，证明本批数值范围内没有夹带 faceforward 规则变化；
  这不是对该既有规则的正确性背书。
- `just shader` 成功：29 编译、2 复用、两个 binding crate 通过。Realtime/Offline closest-hit
  通过 `spirv-val --uniform-buffer-standard-layout`；空白检查通过。
  仅 shader lib/payload 注释改变，无共享 ABI/layout 迁移，未重复完整应用构建。

现在读取真正的 trace 几何法线。forward_normal 继续服务 BRDF 与 GBuffer/RR，object_normal
继续诊断 mesh 插值数据；没有把一份法线改名后强行用于所有职责。几何侧 debug 图和 SHARC
