## 局部修复一：独立累计 roulette 权重

**P1：互相抵消的 eta 因子先溢出/下溢。** 旧 path 先累计含 eta² 的 radiance throughput，
再累计 eta 倒数平方，roulette 时相乘。多次进入界面后，后者可能溢出，即使理论存活权重
仍为普通有限数；还可能得到 0×∞。这不是用更大 epsilon 或钳制 IOR 可以无损解决的问题。

RtMaterialSample::set_scattering_weight 从同一个已含分支补偿的权重生成 radiance 与
roulette 乘子，仅前者乘 eta²。RtPathState 分别累计，存活后同时除以 p。删除只为抵消
而保存的 transmission_eta/roulette_eta_scale；所有普通、镜面、透射与终止分支通过同一
setter 保持两份度量配套。不改光学参数、实际 radiance 求值、离散分支概率、阈值或 cache
输入；SHARC 仍读取 sample.throughput。新增的都是 shader 局部状态，不改变共享 ABI。

依据：PBRT 当前本地 `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（配置 master），
`src/pbrt/cpu/integrators.cpp::PathIntegrator::Li` 将 beta 中透射尺度从 roulette 决策中
消去。项目 eta=n入射/n出射，与参考 sample eta 方向相反；这里只保持同一消尺度语义，
沿用项目 depth<3、delta 跳过及 [0.05,0.95] clamp，不移植参考的完整策略。

验证脚本 `.temp/code-design/B17-c3/check-path.py` 抽取实际 sampler、path 累计/roulette、
classifier、RR guide 和 RNG，C++ float 在 O0/O2、禁用 contraction 下执行。offset mock，
不执行 GPU trace；事件序列用于检查当前简化界面的数值契约，不是嵌套介质正确性证明。

- 56 组序列覆盖 IOR=1.5/10/100/1000、1–10 次进入、黑/非黑通道，再接普通表面。
  基准 8 组 roulette 权重失效，修改后为零；存活后的权重和补偿检查通过。
- 360 组合法分类/粗糙度组合覆盖普通、rough fallback、镜面、透射，IOR=1/1.5/2.5、
  三种 opacity 和四种受控随机值。radiance 采样权重、方向、PDF、done 的 float32 文本
  与基准完全一致。普通分支的 roulette 乘子与 radiance 乘子相同。
- 48 步正常进入/退出/普通反射及多次存活补偿，与 double 数学链比较，最大绝对误差
  3.70e-7；delta 和前三跳不推进 roulette RNG。
- `just shader`：24 编译、7 复用、两个 binding crate 通过；Realtime/Offline raygen 通过
  `spirv-val --uniform-buffer-standard-layout`。没有共享 ABI 变更，未重复完整应用构建。
  没有 GPU、FTZ/subnormal、寄存器压力或性能验证。

## 局部修复二：随机区间边界

**P3：rnd==p 被额外计入存活。** 基准条件是 rnd>p 时终止，实际 RNG 是 k/2²⁴，
k∈[0,2²⁴)。p=0.5 时完整周期有 8,388,609 个存活值，但补偿仍除以 0.5。
探针使用真实 LCG 生成恰好 0.5 的输入，基准实际 roulette 确认仍存活；第二提交将终止条件
改为 rnd>=p，使存活区间为 [0,p)。O0/O2 的实际 roulette 都拒绝该点；遍历完整 2²⁴ 周期，
使用从源码抽出的比较条件计数，存活数变为 8,388,608。其它路径/采样检查也通过。
该修正不消除任意 p 与离散 RNG 格点不对齐造成的量化误差，不宣称连续概率在所有 float 输入
上严格精确。与权重状态分离可独立回滚；第二次 `just shader` 与两份 raygen SPIR-V 检查通过。

## 模型与数值问题：交 B17-d/B27，只给统一方案

**P1：smooth Surface 丢失 diffuse。** classifier 只看 class/roughness，不看 diffuse 权重；
r≤0.02 的非金属也变成 DELTA_SPECULAR，NEE/ReSTIR 排除，RR diffuse guide 归零。
白色非金属、V=(0,0,1)、L=(0.6,0,0.8) 时，实际 eval 的 BRDF*cos 从阈值处的 0 跳到
下一个 float roughness 的 0.25464794。OpenPBR v1.1.1 本地
`f8d6d947dfae4c9b599965a86c22826ea7a8dbfb`，`index.html` Glossy-diffuse / Microfacet
model 中，specular roughness 不负责消除 diffuse substrate。统一方案须表达复合 lobe 和
离散/连续事件，再同步 NEE/MIS、ReSTIR key/eligibility、RR 与能量分配；不能只改阈值。

**P1：rough Transmission 不是 BTDF。** sample_next 明确回退到普通反射；9 种
IOR/opacity 组合在同一粗糙度和随机序列下产生完全相同的方向/权重。光滑玻璃的 opacity
仍逐界面吸收，非 OpenPBR geometry_opacity，也没有厚度/体积吸收和嵌套介质栈。需要统一
CPU/导入映射、BSDF、路径介质与各消费者；本批不修改既有参数含义或用新 fallback 掩盖缺失。

**P1：实际 radiance 的数值支持域仍未闭合。** 上述 56 组序列中，4 组实际 radiance
已经下溢；独立 roulette 权重没有恢复它。另用合法有限 HDR base_color=1e20、metallic=1
连续三次镜面事件，真实 sampler/path 的 throughput 溢出，随后 0×∞ 使 radiance 非有限；
修改前后都能复现。仍需定义 IOR/HDR/路径长度支持域、累积表示与异常语义，结合 B17-c1
临界精度和 B17-c2b 法线模型统一设计。不能将拒绝/截顶极值或更高精度单点运算当作完整解法。

本批不修改 public API、资源/线程/销毁责任或 RenderGraph；局部新增权重属于 path 自己的
积分状态。两份状态增加局部寄存器需求，GPU 性能影响未量测。下一批进入 B17-d；
B18 接收路径估计器策略，B19 接收复合 lobe/key 契约，B27 保留全局模型及数值支持域提案。
