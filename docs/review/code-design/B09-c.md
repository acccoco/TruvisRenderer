## 局部发现

- **P2：灯光注册无校验。** 编辑已有位置/辐射值、spot 锥角与 area 编辑投影约束，注册却
  直接插入并推进版本。NaN、负 radiance、零方向和退化半轴可以进入 CPU owner 与 GPU。
  注册改为 Result，在插入前复用 LightPatch/AreaLightShape；spot 注册与编辑共用归一化，
  已归一化值保持原值。失败不增加记录或推进版本。App 内置场景显式处理错误。
- **P2：Rect 绕序与法线相反。** XY Rect 标注 +Z，但索引叉积朝 -Z；现反转两个三角形
  索引顺序，不改位置、UV、法线或尺寸，保持正面与声明一致。

保持 CPU owner、线程、灯光模型与 ABI。不新增灯光包装层、通用校验框架或兼容入口。
公开注册 API 改为 Result，仓内调用方同步迁移；不把编译通过等同于 GPU 验证。

## 验证与交接

`.temp/code-design/B09-c/{run.py,probe.rs}` 编译基准/当前 World 源码快照并调用实际编辑路径。
38 组非法注册覆盖三类灯的 NaN/无穷位置与 radiance、负 radiance、spot 退化方向/锥角、area
退化/非矩形/不可表示半轴。旧版全部发布，新版全部拒绝且记录数、scene/light revision 不变。
合法注册、spot 归一化、HDR、锥角边界、旋转/翻转 area 轴、typed target、失败与 no-op、
组合编辑只推进一次版本、保留未编辑字段及终止清空后的 stale handle 均通过。

GameWorld 的 edit facade 与 SceneReadView 没有另存权威副本；LightTarget 区分不同 SlotMap，
裸 key 不可跨类型解释。TransformTrs 是按需编辑投影，既有重组校验拒绝 shear，不应替代
instance 的一般 affine 契约。procedural 的局部无状态生成函数无需为统一外形再套框架。

`destroy_scene_mut` 当前唯一调用者是 Runtime shutdown，清空候选与 sky revision 符合终止
语义，不是可继续 prepare 的 reset API。正常与重复清空的 CPU 路径已验证，GPU 销毁顺序
仍归 B12/B27。u32 light revision 饱和后不再区分编辑属于容量边界，交 B27 评估，未改变 ABI。

全部内置几何的新旧 CPU 夹具覆盖 SubmeshData 校验、真实 World 注册、每个三角形的
非退化面积/绕序、单位法线及非零切线的正交与 handedness。Triangle 1、Rect 2、Floor 2、
Cube 12、UvSphere 3968 个三角形均逐一检查；旧版仅 Rect 的 2 个三角形反向，新版全部
朝向顶点法线。零 tangent 继续由上传路径从 UV 重建，不增加另一套生成算法。

World build、现有 4 个 lib 测试和 `cargo check --offline --locked -p truvis-app` 通过；
Rect 修改后的 World 测试再通过，`git diff --check` 通过。没有运行 GPU；CPU 数值与编译
不证明灯光采样、raster 剔除或最终画面效果。
