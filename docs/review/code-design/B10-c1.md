# B10-c1：Material FIF buffer 构造与关闭

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准 `4926ec0a`，分支 `refactor`。B10-c 分为 native buffer 生命周期和 slot/上传状态两个
子批。本轮覆盖 gpu_material_store.rs 中 MaterialBuffers::new/destroy_mut、
GpuMaterialStore::new/destroy/Drop，并追踪 GfxStructuredBuffer 的成对分配与叶子回收契约。

## 发现与修复

- **P1，已修复：stage 创建失败遗失 device buffer。** 原 MaterialBuffers 的 struct
  字段依次构造，第二项失败时第一项只有普通 Rust Drop，没有显式 native 回收。现在
  先持有 device buffer，stage 失败时立即撤销 device，释放诊断不覆盖原始构造错误。
- **P1，已修复：后续 FIF 创建失败遗失此前完整 buffer 对。** 原 array.map 在中途异常
  时丢弃已构造值；现在用固定大小 Option 数组逐项记录，全部成功才交付正式数组。
  任意失败撤销此前所有已完成的对，无新增 heap 集合或通用构造框架。
- **P1，已修复：释放日志异常跳过其余 buffer。** MaterialBuffers 完成 device/stage
  两个叶子释放后返回首个异常，store 再完成全部 FIF 的释放后传播首个异常。正常关闭
  沿用 Shutdown 原因；未提交构造回滚使用 ImmediateRelease。
- **P2，已清理：只有日志的 Drop。** 该实现不释放资源，且在显式 destroy 的 unwind
  过程中可能再次调用会 panic 的 logger。删除此冗余实现；native 资源仍要求显式
  destroy，未增加隐式回收或改变 GPU 安全点。

职责仍由 MaterialBuffers 聚合每对 buffer，GpuMaterialStore 聚合 FIF 数组。CPU 集合
分配先于 native 准备，已完成数组只在所有元素就绪后移交。维持 FrameLabel::COUNT、
MAX_MATERIAL_COUNT、device/staging 布局、slot/revision/dirty/pending_commits、公有 API
和线程边界，无 shader ABI 或上传命令变化。模块 README 同步生命周期约束。

## 验证与边界

`.temp/code-design/B10-c1/{run.py,mocks.rs,main.rs}` 抽取基准/当前实际字段、buffer 对
构造/销毁、store 构造/销毁与旧 Drop，使用实际 FrameLabel、真实 slotmap/log，以及
只记录 native owner 计数和失败点的 GfxStructuredBuffer 替身。材质数据/ABI 在本夹具
中仅为占位类型，未运行 slot 同步、mapped payload 或 shader 布局验证。

20 类新旧对照，在 debug assertions/overflow checks 同开、同关时各运行一次，共
80 次进程运行满足各自预期：正常初始化与关闭、Drop 日志失败、六个创建位置逐一失败、
第 2–6 次创建失败叠加全部回滚释放诊断失败、六次关闭释放逐一失败、全部关闭释放诊断
失败。新版回滚计数归零、原因均为 ImmediateRelease，构造原错误保留；关闭计数归零
且保留首个释放错误。旧版会残留创建位置前的 native 对象或释放位置后的对象。

正常构造仍提供三个 buffer 对、1024 个空 slot、首个可分配 slot 0、空 revision/prepared/
dirty/pending 集合和原 frame id。叶子替身释放后再抛诊断错误，匹配当前 GfxBuffer 的
release-before-log 顺序；没有模拟 native allocator/free 失败。替身不触发 RHI Drop
断言，以便观察旧版泄漏；真实 debug unwind 可能直接终止。

`cargo check --offline --locked -p truvis-render-runtime`、
`cargo check --offline --locked -p truvis-app` 和 `git diff --check` 通过。
未运行 GPU、完整构建或图像回归，不宣称 driver 生命周期或整个 Runtime 失败退出已验证。
显式关闭仍要求消费者停止且 GPU 使用已完成；外层 owner 的聚合失败处理仍交 B10-d/B12。

本报告所在提交包含修复、模块说明与清单，无额外文档提交。
