## 发现与修复

- **P2，已修复**：单 FIF 六个 buffer 及三 FIF 的组合构造缺少回滚，后项分配失败使
  前项丢失显式释放机会；关闭的首个释放诊断异常也会跳过后续叶子/帧。现在三个局部
  typed device/stage pair 分别接管资源，组合构造失败撤销已完成候选；关闭尝试全部
  叶子再传播首个异常，回滚诊断不覆盖原始构造错误。
- **P2，已修复**：SceneStore 的合法注册没有 512 数量限制，GPU analytic 每类却固定
  512，513 个光源会在 prepare 时 panic。512 现为初始容量，当前 FIF 按所需数量以
  checked power-of-two 扩容；候选 pair 完成后接管字段，再释放旧 pair。后项分配或
  释放诊断中断时，已完成候选和原有未替换资源仍有 owner，dirty 保持到提交确认。
- **P3，随容量修复**：三类表原先复制整个预分配容量，连空类别也录制复制。typed pair
  现共享有效前缀上传，空类别由 count=0 表达；不声称已测得性能收益。

## 设计与状态边界

复用 SceneBuffers/MaterialBuffers 已有的候选与显式回收模式，避免让 analytic owner
依赖另一个场景 owner。新私有 pair 只组织三类灯光共有的状态与操作，没有跨模块框架、
额外 trait 或兼容分支。CPU scene 仍是灯光权威；公共 API、Shader ABI、屏障 mask 和
prepare 顺序不变。扩容/写入要求当前 FIF 已等待完成；关闭要求所有 FIF 无 GPU 使用。

sync_scene 根据 CPU light revision 生成副本，清零共享结构 padding，并使所有 FIF dirty。
update 只上传当前 FIF，全部录制成功后登记 pending；Runtime 提交成功后确认并清除该
FIF dirty。绑定地址来自当前 pair，计数/version 来自同一 CPU 投影；其它 FIF 在下次
使用前上传。减少灯光不缩容，但复制范围及绑定 count 随快照缩小。

现有 pending bool 依赖 Runtime 的同帧 prepare→submit→commit 顺序，不支持上传待确认
期间重新 sync 新 revision 后再确认旧工作。本批不增加自动重试或跨 prepare 事务；
失败后 native command 的处置、阶段能力与提交确认约束交 B12。单字段 update result
是否可直接返回 binding，留 B11-e 的组合入口/冗余汇总一起复核。

## 验证

临时夹具位于 `.temp/code-design/B11-d1/`，编译实际 analytic 模块、FrameLabel 和生成
GPU 类型，替换 Scene 读视图、buffer 分配/释放、command 为受控实现。未新增源码单元测试。

- `run-life.py`：正常、分配第 1–18 项失败、关闭第 1–18 项诊断异常、构造回滚伴随
  释放异常共 54 类；基准与生命周期修复分别启用/关闭 debug assertions 和 overflow
  checks，**216 次通过**。核对候选/存活数量、错误保留、重复关闭。夹具不实现 native
  wrapper 的 debug Drop abort，遗漏数量不表示旧运行时可恢复。
- `run-upload.py`：以生命周期提交为容量修复基准。前后 16 类共同用例，修复后另有
  16 类故障/溢出用例，两种 assertions/overflow 配置，共 **96 次通过**。覆盖三 FIF
  的 projection/padding、binding count/version、dirty/pending/commit、稳定帧不重传、
  空/删除后前缀，以及各类 513 个灯光由旧版拒绝转为 1024 容量上传、缩减后不缩容。
- 扩容故障覆盖六次分配、六个旧叶子释放、三次 stage 分配失败伴随回滚诊断及容量
  算术溢出；确认当前 frame 保留完整 pair、其它 FIF 地址不变，局部重试重传全部数据。
  map/flush/copy/barrier 各三个故障点均不提前登记 pending 或清除 dirty。
- 两个提交均通过 `cargo check --offline --locked -p truvis-app`（包含 Runtime）；
  `git diff --check` 通过。受控重试仅验证 owner/CPU 状态，不验证部分 native command
  可直接再次提交。未运行 GPU/RT/raster 或大量光源性能回归。
