## 局部问题与方案

- **P3，Ctx 冗余字段**：SubsystemRenderCtx 转发 device_ctx、device_info_ctx、timeline，
  所有当前消费者均不读取这三项。具体 Renderer 仍用 Runtime render Ctx 提交队列和
  timeline；删除子系统副本不删 Runtime 能力。resource_ctx/queue_ctx 被 ImGui 的
  per-FIF mesh 扩容、上传及队列标签使用，不能一并删除。
- **P3，诊断语义误导**：ViewAccumState 仅被 FrameStatsOverlayData 消费，按相同相机
  签名的 update 次数递增；首次/变化/reset 为零，溢出饱和。UI 的 Accum Frames 和
  “temporal 状态”注释容易被误认为 GPU 已累计样本/提交数。改为 Stable View Updates
  并澄清语义；不改变计数、reset、UI 读取时点或引入一份新的计数状态。

架构预检：第一组收窄 renderer-kit 的现有 Ctx public 字段，不新增上下文或 trait；
第二组归诊断视图及其说明。依赖方向、owner、线程、GPU 生命周期和 pass 顺序不变。
编译覆盖主体和两个 sample 的全部当前 Ctx 消费者，不保留兼容字段；相关文档随各组提交。

## 已确认边界

- RendererClient 是 App 到 Renderer 的实际注入点，有 TruvisAppClient 和 CornellAppClient
  两个实现；前者持有请求 receiver，后者只处理场景。Renderer 不依赖 Tauri/App。
  SubsystemLifecycle 仅表达静态 owner 的 init/resize/shutdown，没有注册或自动调度。
- init 先 Client 场景/相机，再 DLSS 配置与六个 GPU 子系统；shutdown 先停 Client 接收，
  再释放 DLSS feature，之后逆序关闭 ImGui/viewport/outline/SDR/offline/realtime。
  这不是全体初始化调用的严格逆序。SDR 资源固定尺寸且 on_resize 空操作，主体未转发
  此回调不构成当前遗漏；未来改变 SDR 尺寸契约须同步 owner 调用。
- UI 可见性只控制控件构建。Offline/post-process normalize、debug 候选更新和 DLSS
  update 均位于闭包之后的固定路径；模式切换通过枚举选择图，requested/effective
  分属用户意图/设备派生，Offline 强制 native 不覆盖 requested。SDK 失败/释放细节 B16。
- DebugImageSelection 只存 ID/visible，隐藏仍可归一化；无候选清空，有效选择保留，
  失效选择转第一项。具体图像在 render 解析，UI 不持有 GPU 资源身份。
- Runtime 的 RenderView、DLSS motion/jitter、Offline sample count 与 UI 稳定计数
  有不同的更新条件，不能为“去重”合成一个计数器。无 acquired image 仍可能 update；
  UI 在本次 update 的计数推进和 after_prepare invalidation 之前读取前次结果。

## 跨批问题

- **P1，已确认失败清理缺口**：init 或 shutdown 中任何一个 hook panic/expect 失败，
  后续 hook 不执行；RenderLoop 也不会继续其普通 Runtime 销毁分支。这与 B12/B13
  已记录的异常退场链相连。子系统可能持有部分资源或未知提交状态，不能仅加统一 catch
  就保证可继续释放；交 B15 的子系统 owner、B16 的 feature 失败策略及 B27 全局方案。
- Render Ctx 不提供 CPU World 写入，但 resource/queue/record 能力仍可操作 Vulkan；
  裁剪三个未使用字段不等于权限沙箱。init/resize 的可变 FrameRenderState 和尺寸合法性
  缺口延续 B12-d，结合 B15/B16 后在 B27 汇总。
- Realtime sharc_scene_scale 当前从公开设置直接进入 pass，UI slider 限定 1..500，
  没有固定 normalize。是否会破坏缓存地址/尺度与历史，需要 B15/B20 对照 shader 契约；
  本批不凭 slider 范围重写算法参数。其他采样模式/开关由 enum/bool 表达，不再新增总配置层。
