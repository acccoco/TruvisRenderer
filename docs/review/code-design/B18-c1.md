## PDF 消费端

**P2：固定分母下限改变已生成样本的权重。** RtMaterialSampler::sample_diffuse 与
RtDirectLighting::shade_candidate_with_mis_weight 记录/使用真实 PDF 进行 MIS，却在
贡献除法中改用 max(pdf,1e-7)，使低概率方向衰减为应有值的 pdf/1e-7。

现对有限正 PDF 直接相除；材质的非法 PDF 将散射权重/PDF 清零并终止，直接光
shade/target 拒绝非有限或非正 PDF。没有重新采样、修改 class/BRDF 混合概率或增加
fallback。shader 局部状态与既有 owner 不变，无 ABI、线程、资源、pass 顺序变化。

对照本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a` 的
`cpu/integrators.cpp::PathIntegrator::SampleLd`：按实际 light PMF×方向 PDF 求贡献，
无固定分母 floor；本项目保持既有 power heuristic、analytic MIS=1 与 BSDF 模型。

`.temp/code-design/B18-c1/check-pdf.py` 抽取实际 sample_diffuse、shade、target、
RtMaterialSample 与 Mis；mock BRDF eval/PDF、方向采样和 offset，以隔离消费端契约。
C++ O0/O2 关闭 contraction；8 个正 PDF 从 1e-30 到 1e10，构造可表示的 BRDF/PDF 比，
三个低于 floor 的样本在材质与直接光端均从错误变为正确，最大绝对误差从约 .6 降至
2.77e-8。0/-1/Inf/NaN 四个 PDF 的材质错误接受从 4 降至 0；三个 shade/target 入口
合计错误接受从 6 降至 0。这里不证明真实 BRDF 采样分布或全部随机方向支持域。

`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
通过 `spirv-val --uniform-buffer-standard-layout`。未执行 GPU 图像、FTZ 或完整应用构建。

## Roulette 返回值

**P3：RtRussianRouletteResult 只包装一个有效布尔值，throughput_scale 从未被消费者读取。**
原函数已经更新路径的两份 throughput，却另行暴露补偿系数并注释让调用方保持能量一致，
容易诱导重复补偿。全 Renderer shader 搜索确认仅两个 raygen 消费 survived。

现直接返回 bool，Realtime/Offline 只据此 break；删除包装类型、keep 工厂和未使用字段。
存活概率、delta/前三跳跳过策略、随机槽及两份状态的更新顺序不变，未抽象出新的终止框架。

`.temp/code-design/B18-c1/check-roulette.py` 抽取实际 make/roulette 与状态字段，
mock 可控 RNG，遍历七组 RGB 权重、delta 开关、depth 0–5 和八个随机值，共 672 组，
含 clamp 两端及 rnd==p 边界。O0/O2、修改前后，存活/随机推进/两份 RGB 权重的完整
输出相同；同时按预期概率断言分支与补偿，radiance 未被修改。
这验证返回包装清理的行为等价，不是重新证明完整路径或概率 RNG 分布。

再次 `just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
SPIR-V 验证通过，旧返回类型/字段在 Renderer shader 中无残留。没有 GPU 运行验证。
