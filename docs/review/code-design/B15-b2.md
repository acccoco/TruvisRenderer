## 局部修复

- AutoExposurePass 依次创建三个 ComputePass；后一个失败会直接 Drop 前面的 kernel。
  单个 ComputePass 已回收自己未完成的 pipeline/layout，但没有替组合 owner 回收前缀。
  本批保存已完成 kernel，在失败时逐个 destroy，保留原始构造错误；这里没有 GPU 提交。
- SdrResources 的 LUT 上传额外补了一次 transfer→compute barrier，并注释通用 helper
  只覆盖 fragment。当前 GfxImage::transfer_data 已以 ALL_COMMANDS/SHADER_READ 和
  SHADER_READ_ONLY_OPTIMAL 结束；本批复用该契约，删除重复 barrier。

资源仍由原 owner 显式管理；不在 Drop 调 Vulkan，不新增 cleanup 框架。不改变 pass 顺序、
提交次数、shader/ABI 或 LUT 字节。组合构造与未知提交状态沿 B15-a5/B16 的交接处理。

## 公式、格式与职责复核

| 入口 | 静态核对结果及保留理由 |
|---|---|
| `AutoExposureMeter` 与三个 exposure entry | Clear→Histogram→Reduce 的 graph 声明与使用一致；histogram 的读改写、Reduce 的历史读写均声明 storage read/write。三个 kernel 有不同同步阶段，不合并为通用 pass 框架。 |
| 测光与历史 | 非有限/非正亮度不入 bin；256 bins 覆盖 log2 亮度 [-12,20]，使用 bin 中心和 CDF 边界部分权重。空 histogram 保留历史及待 snap；有效输入才消费 snap；适应以 dt/tau 计算，dt 上限 0.25 秒。历史提交确认见 B15-b1。 |
| 参数与 CPU/GPU 矩阵 | normalize 处理非有限值、范围和成对顺序。白平衡由 CPU 合成，glam 按列存储后转置成 push constant 的行向量，与 shader dot 一致。tonal gains 在 CPU 转 stops；不是 shader 中重复求指数。 |
| AgX/ACES | AgX 的矩阵、log 范围及 LUT 与固定参考匹配；2D atlas 对 RG 双线性采样并插值相邻 B slice，对应 3D trilinear 的几何布局。ACES 拟合在 v>1 时同除 v²，保留有理式并规避平方溢出。未据此宣称跨 GPU bit-exact。 |
| 调色/Neutral | 白平衡和 LMS 系数对照固定 Unity 源码；对比度使用项目的中灰亮度公式，分区使用固定 Rec.709 亮度与标量增益。PBR Neutral 保留参考常量及解析公式；负通道归零，不宣称完整 gamut mapping。 |
| SDR→Resolve | radiance 通道使用显示变换；数据通道绕过该变换。dither 在 sRGB 编码空间加入后解码回线性；Resolve 不再手动编码，默认 R8G8B8A8_SRGB attachment 完成最终编码。此结论只覆盖默认 SDR surface 契约，不覆盖任意 HDR/UNORM 输出。 |
| LUT 上传/读取 | `GfxImage::transfer_data` 末尾已声明 TRANSFER_WRITE→ALL_COMMANDS/SHADER_READ，转入 SHADER_READ_ONLY_OPTIMAL；SDR sampled descriptor/graph 使用同一只读 layout。固定 LUT 与曝光 history 分属不同资源，不合并 owner 或改变历史生命周期。 |
