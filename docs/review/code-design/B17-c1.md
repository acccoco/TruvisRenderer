# B17-c1：光滑透射界面的数值边界

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准 `be22229f`，`refactor`，初始工作区干净。B17-c 按介质数值与法线/分类拆分，
本批覆盖 `RtDielectricInterface`、delta transmission sample、RR 直接调用及 path eta 消费边界。

## 已复现的问题（P1）

CPU 允许任意有限 IOR≥1，但原界面先计算 eta²。出射侧 IOR=1e20 的正入射会产生
`Inf*0`，继而得到非有限 Fresnel；近法线的 `1-cos²θ` 丢失横向角度，错误判断 Snell/TIR。
折射方向 `eta*ray+(eta*cos_i-cos_t)*normal` 也会在大 IOR 下相消，丢失正常方向。
RR 已复用该接口，因此同一错误可同时污染路径与 guide。

临时夹具已对修改前实际函数复现：324 组界面、15 组旋转正入射、1944 组确定性分支采样；
O0/O2 均出现 13 个非有限界面结果、60 个非有限 sample，另有 Fresnel、方向或 TIR 偏差。
这些是选定输入的失败计数，不是场景概率或 GPU 故障统计。

架构边界：在现有 interface 内按 Snell/Fresnel 的等价形式改善 float32 求值，仍由它统一
提供方向、eta、Fresnel/TIR；不增加 IOR 上界、不改 CPU/ABI、不更改 opacity/分支概率、
资源、线程或 RenderGraph。源方向与 forward normal 必须单位化且朝向一致；来源的几何/着色
法线问题继续 B17-c2，不能靠数值截断掩盖。

## 修改与验证

本批一个提交，即本报告所在提交。先用叉积构造切向分量并乘 eta，再求其长度平方判断 TIR；
非 TIR 方向由该切向量和独立的透射法向组成，避免大数相减。Fresnel 使用 IOR≥1 缩放比值，
两偏振项在进出界面时交换次序，其非偏振均值不变。未改变 IOR=1、opacity、分支随机数、
透射颜色或 radiance eta² 语义。TIR 临界判定仍为当前 float32 结果是否达到 1。

公式对照本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（manifest 浮动 master）
`src/pbrt/util/scattering.h::FrDielectric/Refract`；项目 eta 为 n入射/n出射，和 PBRT 的相对
IOR 参数互为倒数。这里按项目方向约定重排数值计算，不直接复制其平方与方向相减的求值顺序。
OpenPBR 的参数目标与已有逐界面 opacity 偏差仍沿用 sampling 设计文档的固定 v1.1.1 依据。

`.temp/code-design/B17-c1/interface.py` 抽取实际界面和 delta sample，C++ float 适配，
O0/O2 禁用 FP contraction；RNG 用确定值，offset helper 为桩，不据此验证起点偏移或 GPU。
15 个 IOR 从 1、1 的下一可表示值、1.33/1.5/2.5 到 f32::MAX，覆盖正入射、普通角度、
近法线、小角度临界锥内外、出入两侧、旋转的严格正入射；sample 另组合三种 opacity 和两个随机端点。

| 指标 | 基准 | 修改后 |
|---|---:|---:|
| 324 界面 + 15 旋转正入射中的非有限结果 | 13 | 0 |
| 1944 个 sample 的非有限结果 | 60 | 0 |
| 临界舍入带外最大 Fresnel 绝对误差 | 0.0332503 | 2.11e-6 |
| 临界舍入带外最大方向向量误差 | 1 | 7.64e-7 |

**临界精度未解决。** 探针将 3 个 `|eta*sin_i-1|<1e-5` 的出射输入单独记录；该范围只是
夹具分类，不是实现 epsilon。所有输入都检查有限性，但这些输入没有被计入 Fresnel/方向精度
通过项。具体反例：IOR=10000、float sin_i=0.0000999999974738，double 参考仍可透射、
F≈0.573801；修改后 float 乘积舍入为 1，判断 TIR、F=1。基准虽未判断 TIR，F≈0.999600
同样严重失准。该反例明确保留，不能声称全参数精度通过，也不能用放宽通过阈值掩盖它。

复跑 B17-b2 的常用 IOR≤2.5 guide/镜面/rough/PDF 与白炉夹具，结果通过且能量结论保持；
透明 guide 最大参考误差为 1.38e-6。`just shader` 成功（24 编译、7 复用、两个 binding crate
通过）；Realtime/Offline raygen 均通过 `spirv-val --uniform-buffer-standard-layout`，空白检查通过。
无共享 ABI/host 代码变更，未重复完整应用构建。

## 下一批交接

- **P1，B17-c2 已确认：** surface_hit 的 origin_normal 实际由插值顶点法线经 inverse transpose
  得到，并非三角形几何法线。界面用它判断出入，ray offset 也用它。例：几何法线 (0,0,1)、
  合法单位插值法线 (0.8,0,0.6)、ray=(0.8,0,-0.6)，前者判进入，后者判退出；不能靠稳定
  Fresnel 公式纠正错的介质侧。下一步读取 GeometryEval/triangle 顶点、负缩放与 winding 契约。
- **B17-c2：** faceforward 使用 origin_normal 选择翻转，但 normal map 的 shading normal
  不一定与入射方向处于合法半球；还需核对 reflection/refraction、offset、ReSTIR/RR 的法线用途。
- **B17-c3：** 未证明长链 throughput/roulette_eta_scale 不会溢出；极大 IOR、HDR base color
  与多次透射积累需要单独检查。当前仍无介质栈，光滑 Surface 去除 diffuse、rough BTDF fallback
  的模型问题也未闭合。临界高精度/支持域方案最终与 B17-d/B27 的模型提案一起列出。
- 修正旧说明：全仓实际只有 delta sampler 和 RR guide 调用该 interface，没有透明 motion
  direction 调用。当前 primary instance motion 不等于折射运动；已同步活跃设计和函数注释。

下一批 B17-c2，B17 保持进行中。没有 GPU 场景、设备 subnormal/FTZ 或图像验收，
CPU 临界舍入与 GPU 数值行为不得混同；不实施最终全局模型迁移。
