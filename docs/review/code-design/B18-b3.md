## 球形 point/spot 采样与重建

**P1：窄锥消减与交球判别式使远处光源消失。** 原 solid angle=2π(1-sqrt(1-r²/d²))，
不仅相减损失精度，还以 1e-7 sr 下限丢弃；射线求球的 b²-c 又在两个大数间相减。
采样点通过 surface.position+direction*distance 再减 center 恢复 key normal，大坐标下
进一步丢失 0.005 m 的半径信息。原重建还容许距离×1e-3 的“最近命中误差”，可能接受背面点。

现由 RtDirectLighting::sphere_cone_parameters 共享稳定锥高 q=sin_max²/(1+cos_max)，
以 q_sample=u*q 与 sin²(theta)=q_sample*(2-q_sample) 构造可见锥。直接计算球面法线：
令 k=r/d、h=sqrt(1-sin²(theta)/k²)，则 cos(alpha)=sin²(theta)/k+cos(theta)*h，
sin(alpha)=sqrt(sin²(theta)/k²)*(cos(theta)-k*h)。使用已有 Sample 基向量转换，
key 直接保存法线；连接向量为 (center-surface.position)+r*normal。

重建按相同相对向量计算方向/距离/PDF，并以 normal·(-light_dir)>0 检查可见半球。
删除无其它调用者的 ray_sphere_nearest_hit，消除平行的交球模型和随距离放大的容差。
采样和重建均按最终有限正 PDF 判断可表示性；拒绝非有限参数/非法 key，保留球内与
radius+distance_guard 的拒绝域，不给这些视点伪造 uniform 或 delta 光源。

参考本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（resources.toml master）
`shapes.h::Sphere::Sample/PDF`：沿可见锥采样并直接生成球面法线/点。本项目用有理化
恒等式替代其小角度 Taylor 分支，并稳定计算 sin(alpha)；不移植球内采样、误差区间或 shape 框架。
修改归属已有 RtDirectLighting，未改 ABI、CPU light 单位/强度、资源 owner、线程或 RenderGraph。

## 隔离数值证据

`.temp/code-design/B18-b3/check-sphere.py` 抽取实际 sphere sample/reconstruct、Sample 基向量、
candidate/key 和 radius；C++ float O0/O2、关闭 contraction。mock RNG/class 数及 visibility
构造（直接保留 distance），因此这里验证几何采样而非真实偏移 shadow ray 或遮挡。
七种名义距离 0.00501/0.01/0.1/1/10/100/1000 m，两个原点尺度 0/10000，轴向/斜向，
64×8 个随机区间中点；真正不在球外的输入预先剔除，共 13,312 组。

| 指标 | 基准 | 修复后 |
|---|---:|---:|
| 有效采样候选 | 9,120 | 13,312 |
| 同视点可重建候选 | 7,264 | 13,312 |
| PDF 相对误差超过 1e-5 | 5,536 | 0 |
| PDF 最大相对误差 | 0.048576 | 3.06e-7 |
| 10 个背面 key 对照中错误接受 | 3 | 0 |

原实现 100/1000 m 候选全部丢弃。有效样本的重建 PDF 均包含一次 class 因子，
与采样条件 PDF×class_pdf 一致。PDF 参照以相同 f32 center_distance 构造 double 有理化公式，
不声称验证了任意世界坐标的真实几何距离。球内、半径边界及零/Inf/NaN key 对照通过。

另以 double 的真实连接角反算 CDF，暴露浮点方向的误差：10 m 从 0.26552 降至 0.0002501；
新增可采样的 100/1000 m 分别仍有最大 0.002352/0.026133。靠近球面的 0.00501 m 从
3.44e-7 增至 3.99e-5，反映由球面 key 重建方向的舍入，不能宣称所有距离精度都改善。
`check-boundary.py` 用真实 RNG 可输出的 0 与 1-2^-24 替换两个槽，104 组中有效/可重建
从 54/40 升至 104/104；没有非有限输出。该集合不是实际随机路径错误率或完整分布检验。

`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen 的
SPIR-V 通过 `spirv-val --uniform-buffer-standard-layout`。未执行 GPU 图像、方差、运行期
visibility、FTZ、性能或完整应用构建；CPU 的数学内建函数不能替代 GPU intrinsic 验证。

## 已核对与后续子批

  spot 角度为 radians，area 为单面 radiance。球形辐射没有另乘 inverse-square，衰减由
  solid angle 与后续贡献除 PDF 产生；未将该单位改成数学 delta point 的 radiant intensity。
