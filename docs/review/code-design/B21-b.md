# B21-b：Editor DTO、scene version 与 mutation 一致性

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准 `15bbf3b8`，`refactor`，本子批核对 Editor DTO、opaque ID、分页版本和 Light/Environment/Material
mutation。确认一项局部缺陷并修复：Editor 适配器曾把 `alpha_cutoff` 限制在 `[0, 1]`，与
`MaterialData::validate` 规定的“有限且非负、允许大于 1”不一致。

## 已核对的不变量

- ID 使用 `prefix:{:016x}` 携带 slotmap generation；解码只恢复预期的 handle 类型，随后仍由
  World 检查 stale handle。Web 不解析 index，也不能混用不同资源类型。
- `GetSceneObjects` 在构造分页前检查 `expected_scene_version`，页面携带同一版本和 next offset。
  Web 只拼接同版本页面，跨版本响应重新从第一页恢复。
- Light、Environment 和 Material patch 都在 RenderThread 串行进入 World。适配器先做 DTO 单位与
  结构转换，World 再做权威领域校验；实际变化才推进 scene version，失败和重复值都不产生变化通知。
- command 没有携带 `expected_scene_version`。当前 patch 是字段级绝对赋值，并由同一 RenderThread
  串行执行；这保证单次修改原子性，但不能检测其他来源在草稿形成后对同一字段的修改，后执行的赋值
  可以覆盖先执行的结果。增加命令版本字段会改变协议和冲突语义，交 B22/B23 核对多入口需求，
  必要时由 B26/B27 提出方案，不混入本批局部修复。

## 局部修复

`WorldSceneAdapter::coverage` 现在只把 `CoverageModeDto` 转成 World 类型，合并后的
`MaterialData::validate` 负责拒绝负值和非有限值，同时保留 `alpha_cutoff > 1`。修复不改变公共
协议、资源所有权、scene version 推进或通知恢复规则。

## 证据与边界

- `.temp/code-design/B21-b-check.py` 从当前 Editor adapter 和 World material 校验源码提取规则，
  检查 adapter 不再调用 unit-range 校验，并覆盖 `0`、`1`、`1.5`、负值、无穷和 NaN 六组边界；
  输出 `alpha_cutoff_cases=6; adapter_delegates_to_world_validation=true`。
- `.temp/code-design/B21-b/` 将完整 `editor_controller.rs` 复制进临时 binary，调用实际
  `WorldSceneAdapter::handle_command` 和 CPU `GameWorld`；
  `cargo run --offline --manifest-path .temp/code-design/B21-b/Cargo.toml` 通过 13 组检查：
  ID round-trip/类别/格式、三组合法阈值、三组非法 patch 的原子性、重复提交、分页版本匹配/冲突、
  删除后 generation 失效。输出 `actual_adapter_world_cases=13`，进程退出码为 0。
  换回基准 adapter 时，同一探针在 `1.5` 用例收到 `[0, 1]` 错误并以 101 退出，复现修复前缺陷。
  临时 crate 使用独立 lockfile；根工作区依赖未修改。运行另有 `SymInitialize` 错误 87 诊断，
  本批未定位该符号初始化问题，不把 CPU 断言通过扩展为调试器或渲染验收。
- 静态核对 `WorldSceneAdapter::handle_command`、`GameWorld::update_material`、
  `SceneStore::update_*` 及 Web 分页/详情请求；未新增协议字段。
- `cargo check --offline -p truvis-app` 与 `git diff --check` 通过。
- 探针验证 CPU 请求与版本/通知结果，不替代真实 WebView 交互、GPU 上传或跨版本并发验收。
