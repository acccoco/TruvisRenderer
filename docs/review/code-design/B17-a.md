## 覆盖与事实

阅读 CPU `MaterialData`/`MaterialClass`、`GpuMaterialStore::build_gpu_material`、Engine material ABI、
`MaterialAccess`、`SpecularBrdf`、`Random`/`Sample`，以及 Renderer 的 payload、surface hit、
raygen material、GBuffer/RR 和 ReSTIR surface key；沿 Realtime/Offline entry 与 direct lighting
确认直接消费入口。未完成完整导入/编辑调用链、法线模型、所有采样分支及估计器审计。

- CPU class 决定 ABI 的 opacity/ior；Surface 与 Emissive 的 ior 固定为 1，只有 Transmission
  保存实际 IOR。MaterialAccess 组合 factor/texture；surface hit 再读取 ABI 的 opacity/ior。
- roughness ≤ 0.02 的表面走 delta；其余非 delta 路径把 roughness 平方作为 GGX alpha，
  diffuse/specular 选择概率分别为 roughness 与 1-roughness，throughput 使用两者混合 PDF。
- Realtime/Offline 共用 `RtMaterialSampler`；NEE 复用其 eval/pdf，ReSTIR 经同一 direct-light
  求值链，SHARC 复用路径材质采样。Engine NDF 不读取 Renderer 资源，未见为本问题增设抽象的必要。
- RR albedo 另有 F0 公式；ReSTIR `surface_from_key` 重建的 ior=1。这两处不应在未来材质
  参数演进时被漏掉，当前不等于 ReSTIR 或 RR 全部契约已验证。

## 已修复：完整 NDF 与低粗糙度精度（P1，已复现）

`SpecularBrdf::ggx_sample` 把均匀随机数截到 [0.001,0.999]，使区间外的概率堆到两个边界，
但 `ggx_pdf` 仍返回完整 NDF 对应的方向密度；这是 sample/pdf 不一致，不是合法的 delta 分支。
原来的 `(alpha²-1)*u+1`、采样 `1-cos²θ` 和 D 中 `1-(NdotH)²` 还会在低粗糙度下相消。
即使实际非 delta 的 roughness 刚大于 0.02、alpha 大于 0.0004，仍可复现较大的数值偏差。

修复仍在现有 `SpecularBrdf`：使用原始 [0,1) 随机数；分母改成 `(1-u)+alpha²*u`，
分别计算 sin²/cos²；D 使用 `|N×H|²` 保留小角度信息。同步纠正注释中的反射 Jacobian：
H 的密度为 `D*NdotH`，方向密度为 `D*NdotH/(4*VdotH)`，不是 `4*NdotV`。

保持 NDF 采样、两次 RNG 消耗、roughness→alpha、Renderer 的混合概率与调用接口。
保留 D/pdf 原有 epsilon，不将本次修复说成任意小 alpha/掠射均严格无偏；本次数值域是
当前合法非 delta roughness (0.02,1]。不改 CPU 材质、ABI、资源、线程、pass 或历史状态。

依据已核对的固定版本：

- OpenPBR v1.1.1，`f8d6d947dfae4c9b599965a86c22826ea7a8dbfb`，
  [Microfacet model / GGX](https://raw.githubusercontent.com/AcademySoftwareFoundation/OpenPBR/f8d6d947dfae4c9b599965a86c22826ea7a8dbfb/index.html)：
  各向同性 NDF 与 alpha=r²；不据此宣称当前材质层符合完整 OpenPBR。
- Filament v1.77.1，`477aee3faa2d402545ebcbb65fb0cf6e1c9d0d0e`，
  [surface_brdf.fs::D_GGX](https://raw.githubusercontent.com/google/filament/477aee3faa2d402545ebcbb65fb0cf6e1c9d0d0e/shaders/src/surface_brdf.fs)：
  采用叉积形式的数值思路；不复制其 mobile 条件编译或 fp16 截顶。
- PBRT 本地 `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（manifest 为浮动 master），
  `src/pbrt/util/scattering.h::TrowbridgeReitzDistribution` 使用 VNDF；本次未把它的可见法线
  PDF 与项目 NDF sample 混用，也没有迁移 VNDF。

## 验证与限制

`.temp/code-design/B17-a/check-ggx.py` 从修改前后源码抽取 ggx_sample、ndf_ggx、ggx_pdf 和
实际 Sample 坐标基，做 C++ float 适配；RNG 替换为受控输入，固定 u/v 槽以排除 C++ 实参求值
顺序差异。clang++ O0/O2 均禁用 FP contraction。不是实际 Slang/GPU 执行。

6 个 alpha（0.0004001 至 1）、3 个法线、15 个 u（含 0 和 1-2^-24）、4 个方位共 1080 组，
分别比较解析 CDF、double 参考 D/反射 PDF、单位长度及两次 RNG 消耗；另对每个 alpha 用
100000 个 double 分位点换元积分，检查 D*cos 的归一化。修复前在两种优化下均复现失败，
修复后全部通过；失败计数不是 GPU 出错概率。

| 数值检查 | 修复前 | 修复后 |
|---|---:|---:|
| 最大 CDF 绝对误差 | 0.32684846 | 0.0000239249 |
| 最大 D 相对误差 | 0.83863081 | 0.0000611552 |
| 最大反射 PDF 相对误差 | 0.83863081 | 0.0000727591 |
| alpha=0.0004001 的 D*cos 积分 | 1.08467065 | 0.999999963 |
| 六组积分最大绝对误差 | 0.08467065 | 4.10e-8 |

`just shader` 成功（29 个编译、2 个复用，两个 binding crate 构建通过）。Realtime/Offline raygen
产物均通过 `spirv-val --uniform-buffer-standard-layout`。无共享 ABI 改动，未新增布局迁移。
空白检查通过；未运行 GPU 渲染、能量白炉图像、性能或长期累积回归。

## 后续项与交接

- **P1，B17-b：参数域未被完整守住。** `MaterialData::validate` 对 metallic/roughness 只查有限性，
  GPU 投影与 MaterialAccess 原样传递/相乘；roughness 也是分支概率，超出 [0,1] 会破坏混合 PDF。

- **P1，B17-b：Surface F0 与能量分配。** raygen 的 rough/delta Surface 和 RR 固定
  dielectric F0=0.1024；OpenPBR 默认 IOR=1.5 对应 F0=0.04。Surface 无 IOR 状态，不能把
  当前 ABI 的 1 直接用于替换公式；ReSTIR key、RR、导入接受条件须一起设计。
  当前 Lambert 不受 Fresnel 能量分配约束：白色非金属的 diffuse 已积分到 1，还叠加正 specular，
  因而不是能量守恒模型。本次 NDF 修复不解决这个偏差。
- **P2，B17-b/d：重复和无效计算。** `sample_diffuse` 的 glossy 分支计算了未使用的 f0；
  eval/pdf 多处构造相同 F0，RR 单独维护公式；`brdf_with_pdf` 标为未来用途。后续连同统一
  材质语义核对真实调用，避免为了删几行先引入另一层 helper。
- **B17-c：** rough transmission 仍回退反射；光滑 opacity 为逐界面透射衰减，非 OpenPBR
  geometry_opacity。法线/切线、双面、delta/半球与极限方向完整一致性尚未审完。
