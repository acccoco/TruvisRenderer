## 机械清理

**P3：RT_INTERSECTION_GUARD 已无引用。** 原球面求交已在 B18-b3 删除，递归检索
Engine/Renderer 及仓库代码只剩 ray_numeric 中的定义。本提交删除该 shader 局部常量，
不改 RT_DISTANCE_GUARD、TMin/TMax 或 offset 算法；无 ABI/生命周期/线程/pass 变化。
`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
通过 `spirv-val --uniform-buffer-standard-layout`。31 个 SPIR-V 中 29 个原始 SHA-256 相同，
两个 raygen 原始哈希不同，不能报告全部二进制逐位相同。

补做有/无常量的受控构建，基准源码文本与 HEAD 一致。原始二进制未完全复现初次快照，
反汇编可见嵌入源码和 Debug 指令差异；未将原始哈希变化解释为渲染行为变化。
spirv-opt 的 debug stripping 在大型 raygen 上崩溃，改用临时脚本按 SPIR-V 指令去除
调试记录，再以工具消去无用常量、统一 ID；处理前后均用带项目 layout 参数的验证器校验。
两个 raygen 的规范化结果完全相同。最终恢复删除常量的源码并重新构建/验证。
证据位于 `.temp/code-design/B18-d/` 的 shader 日志、原始/规范化产物与 comparison JSON。
这证明受控编译产物的等价，不代替 GPU 图像验收。没有新增永久测试。

## B19 / B20 的具体接手点

- **B19：** `restir_di::surface_from_key` 仍将 origin_normal 设为 forward_normal。
  先追 primary key 的生成、持久化、重建、资源与屏障，补齐真实几何法线契约。
  **后续状态：** [B19-a](B19-a.md) 已修复该输入缺口；本报告的原始交接基准保留，reservoir 估计器与 GPU 图像仍需分别验收。
- **B19：** initial 仍用 `1/max(pdf,1e-7)`，与已修复普通 NEE 不一致。
  **后续状态：** [B19-b](B19-b.md) 已移除两处 floor，修复 raw/finalize 的中间范围与非有限状态检查；时空校正调用方的分母构造继续 B19-c。
  需连查 `stream_sample` 的 target×inverse-PDF、权重和、finalize、非有限值及 M 语义；
  不只删除 floor 后把 Inf 带入 reservoir。球面 key 的跨视点面积/立体角 Jacobian、
  class mask、灯光版本、visibility 与 history rejection 均未由同视点夹具证明。
- **反证提醒：** key 重建的 ior=1 是占位值，但当前 rough `surface_f0` 仍为固定 .04
  与 metallic/base_color 插值，rough transmission 也仍为 surface fallback；不能仅凭
  ior 占位就声称当前 rough target 已丢失 IOR 反射。新增材质模型时仍须扩大 key 契约。
- **B20：** 复核 emission 仅传播给历史顶点、cache 保存反射 radiance，以及 Query/Update
  提前终止和版本失效。优先处理 `renderer-rendering/src/realtime/resources.rs`
  `SharcTargets::new` 的三个 buffer 顺序分配前缀回收；B16-c 已确认且当前源码仍存在。
  首次 clear_all 提交前失败可局部修复，提交/等待后的未知状态不能按同一路径释放。
