## 硬深度上限

**P2：NEE 给不存在的 BSDF 竞争样本分配权重。** Realtime/Offline 循环最多 trace 16 次，
SHARC Update 最多 8 次；最后顶点仍生成带 MIS 的直接光，却不会 trace 其 BSDF 续路，
导致权重之和小于 1。此前即使材质采样与 roulette 执行完，也没有下一轮 trace。

现在三条循环按 `depth+1 < limit` 显式传入 has_bsdf_continuation；末顶点 HDRI/emissive
NEE 使用 1，analytic 保持 1。保留末顶点 emission/NEE 与原 trace 数，随后直接停止。
没有额外 trace，也不重定义用户深度配置。随机 roulette 有存活补偿，仍使用原 MIS。

删除三个无调用者的单类 sample_* 包装以及仅转发 MIS=1 的 shade_analytic_candidate，
所有路径 NEE 经显式带续路契约的统一入口；类内候选 sampler 保留供统一采样/ReSTIR 使用。
Realtime 的 primary ReSTIR 替换发生于 depth=0，在固定 16 次上限下仍有续路；未修改
reservoir target/finalize。若未来支持深度 1，必须一起传递 reservoir 的竞争策略。

SHARC 的 SharcUpdateHit 必须在末顶点调用，才能写入/传播已算直接光；之后不再
sample_next 或 SharcSetThroughput。cache resampling 提前终止仍用已有 cache 替换
当前 radiance，不等同缺失互补样本。核对 SHARC 实际子库
`0b9f58bbc8c41736042d4da964830a247e424a00` 的 `SharcCommon.h::SharcUpdateHit`。

对照 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`
`cpu/integrators.cpp::PathIntegrator::Li/SampleLd` 的 emission、深度判定和竞争 PDF。
PBRT 深度含义及截止位置不同；本项目保留现有“末顶点继续 NEE”的策略，故使用单策略权重，
而不是宣称移植了 PBRT 的整个深度策略。delta 末顶点无 NEE，仍被原上限截断。

`.temp/code-design/B18-c2/check-depth.py` 抽取实际 unified shade/MIS/贡献函数，
mock BRDF eval/PDF 与 candidate 数据，C++ O0/O2、关闭 contraction。3 类 ×4 light PDF
×4 BSDF PDF ×2 续路条件，共 96 组：末顶点错误 22→0，非末顶点错误前后均为 0；
修复后最大绝对误差 2.32e-8。两个离散方向的穷举 NEE 积分由 .8923077 恢复至理论值 2。
这验证权重组合，不是实际 BSDF 分布、GPU 路径或图像积分的验证。

静态连接检查确认三条真实循环计算/传递上限条件，并在 sample_next 前退出。
`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
通过 `spirv-val --uniform-buffer-standard-layout`。未执行 GPU 运行或完整应用构建。

## 纯发光终止与 guide

**P3：已终止的 emission 通道仍保留，纯发光还会生成反射 guide。** 三个实际循环已在
sample_next 前累加 emission 并退出纯 EMISSIVE；因此 RtMaterialSample.emission 在
实际续路中恒为零，唯一的非零赋值分支不可达。原 apply_material_sample 再累加该字段
使职责重复且误导后续调用者，但当前三个循环没有因此发生双计 emission。

现在删除材质结果的 emission 字段及消费，保留 add_emissive/SHARC UpdateMiss 为唯一
发光入口。sample_next 对纯发光返回 done=true、两份散射权重和 PDF 均为零；
primary_specular_hit_distance 对同一类别返回已有 65504 无命中值，提前跳过 RayQuery。
普通带 emission 的 Surface/Transmission 不命中该分类守卫，继续保留散射与反射 guide。

已核对配置的 Streamline v2.14.1 ZIP 中 `docs/ProgrammingGuideDLSS_RR.md` §4.1.9：
距离表达 primary surface 上的 specular ray origin 到 hit point。本地 SDK 为归档目录，
不是独立 Git checkout；不将父项目 git hash 冒充 SDK commit。65504 是本项目原有的
无命中约定，不能称为该文档规定的统一 sentinel。未对真实 DLSS-RR 画面作验收。

`.temp/code-design/B18-c2/check-emission.py` 抽取实际 sample_next、材质结果、
add_emissive 与 apply_material_sample；普通散射子函数 mock 为恒等权重。5 类材质 ×
2 个 emission 值，共 10 组，检查纯发光零散射与发光仅累加一次、普通类别不被终止。
旧结果在强制直接消费纯发光采样时有 3 项契约错误，新结果为 0；这是防误用检查，
不是宣称旧 raygen 运行时存在重复发光。RNG 未被终止分支推进。

`check-guide.py` 抽取实际完整 guide 函数及 offset，mock RayQuery hit/miss/计数，
4 类材质 ×2 emission ×2 查询结果，共 16 组：纯发光错误 4→0，query 数 16→12；
其余类别继续查询并保持同一距离或无命中值。没有验证实际 TLAS/alpha-test/DLSS 行为。
两夹具 O0/O2 结果一致。`just shader` 再次 24 编译、7 复用，两 binding crate 通过，
Realtime/Offline raygen 的 SPIR-V 验证通过；`git diff --check` 通过。

## 完整路径扫描与交接

- 三条循环先处理 miss/本地 emission，纯发光退出；普通非 delta 继续 NEE/散射。
  主路径 continuation 保存完整 PDF、未偏移顶点与 delta 标记；roulette 只补偿存活路径。
  SHARC 则把散射权重传给缓存历史顶点，不混用主路径 roulette 状态。

  时先加本地 emission，再以缓存反射 radiance 结束。Offline 不参与这两种替换。
  B19/B20 必须继续验证它们的权重、历史有效性与 cache 量含义，不能据本批共享路径正确推定。

  B18-d/B27 统一说明模型取舍，不在局部批扩大追踪范围。ReSTIR 重建真几何法线缺口交 B19。
