## 发现与局部修复

**P1：成功 payload 可包含 GPU 求逆无法处理的实例变换，已修复。** Reader 原样复制
world matrix；AssetSystem 的 scene payload 校验只检查引用与材质数量，RenderInstanceTable
随后直接执行 f32 inverse。当前入口要求实际发布的 mesh 实例变换有限、仿射、行列式有限
且非零、逆矩阵有限。不是新增文件格式合法性规则，而是明确现有运行时的发布前置。
无 mesh 的 group 仍不发布；负缩放、非均匀缩放及累计 shear 允许。未修改 GPU 求逆算法。

**P2：几何和引用错误延迟到登记阶段，已修复入口检查。** Reader 原先复制后直接返回
SceneSuccess；坏几何到 register_mesh 才经 SubmeshData::validate 拒绝，前面的 mesh 可能已
登记。现在复用同一校验，覆盖非空顶点、属性长度/数值、三角索引和范围；不建立第二套校验。
实例引用在当前 scene mesh/material 数量内才发布；下游已有引用检查，本次没有宣称修复
不存在的索引越界崩溃。其它材质/纹理登记失败仍可能部分发布，事务问题继续交 B09。

局部改动均归 TruvixxSceneReader 私有方法：copy_mesh 完成校验后包装 MeshData，copy_scene
将已查询的数量传给 copy_instance。未新增公共类型、依赖、线程、owner、FFI 或 Shader ABI。
scene guard 仍覆盖所有借用并在成功/失败后释放，返回值仍全部 owned。复用已有几何验证器，
两处格式导入边界的少量变换前置不引入通用框架。无 unrelated 格式化。

风险：之前返回成功的坏数据现在提前失败；非常大/小的可逆数学矩阵也可能不满足当前 f32
路径。此限制与 glTF Reader 一致，不通过 clamp、identity fallback 或伪造法线修饰输入。
检查发生在安全复制之后，不能挽救 native 已违反的指针有效期、实际长度或容量契约。

## 验证

临时文件统一位于 `.temp/code-design/B08-d1/`，不加入仓库测试：

- `run.py` 编译基准与当前完整 Reader、handle/material_texture，替代 task request/result
  外壳；同一组案例分别开启/关闭夹具的 debug assertions 和 overflow checks。依赖/native
  使用现有 Debug 构建，不声称进行了完整 Release 构建。
- 25 个可控 FFI 案例：复用真实 binding 的 POD 类型、以受控数组替代 native getter。
  覆盖非有限 position/normal/UV、零法线、空顶点/索引、非三角计数、越界索引、空属性指针，
  非有限/非仿射/奇异矩阵、det 溢出/下溢、inverse 溢出、首个/后续引用越界，以及正常
  属性、负缩放、shear、无 mesh group、多引用顺序与名称。每例检查 guard 已释放；新旧的
  成功/失败差异与预期一致。人为错误值只证明 Reader 边界，不证明真实格式必然产生它们。
- 12 个真实文件经实际 Assimp DLL：三角形、四边形三角化、无 UV、中文/emoji OBJ，
  以及直接交给 Assimp Reader 的 glTF 矩阵夹具。验证 parent * local 的列主序结果、负缩放、
  shear、共享 mesh，复现零缩放及极端缩放旧版成功、新版失败。生产 worker 的 `.gltf/.glb`
  仍走 Rust glTF Reader，此探针不改变 dispatch。合法结果仍通过现有几何校验。
- 四种新旧/断言组合均通过上述 37 个案例。`cargo build --offline --locked -p truvis-asset`
  与 `cargo check --offline --locked -p truvis-world` 通过；空白检查通过。

未运行 GPU、FBX 或完整 worker→AssetSystem 事务回归。合成矩阵不代替 FBX 单位/轴向验收。

## 续接 B08-d2

以下是已定位的当前代码事实，影响和修复方案仍需格式/参考实现验证，不在本批静默关闭：

- native 只保留 UV0、跳过非三角 face；输出计数存在 size_t→u32 转换，需核对容量边界。
- 材质读取 diffuse、reflectivity→metallic；Rust 将 emission 优先分为 Emissive，并将部分
  opacity 映为 Transmission。需核对原始属性、数值域及发光可反射表面的契约。
- 纹理路径直接拼目录，尚未区分 Assimp embedded 引用；C ABI 未保留多 UV、纹理层与映射。
- skin/morph、动画、相机/灯光未进入现有 RawSceneData，须核对真实输入的失败/丢失行为。
- SceneImporter 构造时创建 Importer，load→clear 又创建一次；是否收敛需连同重复 load/
  失败释放验证。FBX cm→m 的既有处理需按实际锁定 Assimp 版本和样本复核。

B08-d 保持部分完成，下一批 **B08-d2：Assimp native 格式与材质语义**。B26/B27 最终全局修改不实施。
