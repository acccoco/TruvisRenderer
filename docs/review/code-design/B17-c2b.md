## 局部修复

**P1：BSDF 的着色有效域不一致。** surface hit 的 faceforward 以插值法线判面，而不是
最终 normal map 法线；真实 normal map 可产生 Ns=(0.8,0,0.6)，观察 V=(-0.8,0,0.6)，
Ng=(0,0,1)。此时 Ng·V=0.6，但 Ns·V=-0.28。原 BRDF 只检查 Ns·L，PDF 两侧均未检查，
采样也没有拒绝背向观察输入；镜面/Snell/Fresnel 会在不满足当前定向前提时继续执行。
V=-L 时还可能在 normalize(V+L) 中产生非有限结果，不能由末尾乘零证明安全。

修复复用既有 owner：RtSurfaceHit 提供严格正着色半球谓词；普通反射的 sample/eval/pdf
同时要求 V、L 合法，delta 的连续值/PDF 为零。RtDielectricInterface 显式返回 valid，
无效观察输入在 Snell/Fresnel 前返回零反射，调用方终止；IOR=1 没有界面，保留直通。
普通镜面和 RR 使用同一有效域。拒绝的采样设 done/零 throughput，普通采样 PDF 为零；
不重采样、不归一化剩余方向，不改变合法域内的 GGX/Lambert、Fresnel、分支概率或 eta²。
发光仍先处理，与着色有效域无关。Realtime/Offline/SHARC 的路径都在 done 后停止续路。

这里的正半球是当前 forward-normal 模型的定义域，不能将它当成真实几何半球，亦不能将
零贡献处理宣传为法线扰动的能量补偿。坏着色方向可能呈现暗区，仍需后述统一模型与画面验收。

## 验证

`.temp/code-design/B17-c2b/check-hemisphere.py` 抽取真实 payload 谓词、Sample、SpecularBrdf、
RtMaterialSample/Interface/Sampler 和 RR guide，转为 C++ float；O0/O2 均禁用浮点 contraction。
随机数使用受控序列，修正 C++ 参数求值次序以保留 shader 的随机槽顺序。offset 使用 mock，
不执行纹理采样或 GPU trace；本批没有修改 offset 算法。

- 648 组 eval/PDF 覆盖三种 frame、正/负/零余弦、三种粗糙度与金属/非金属。
  基准无效域中 162 组 eval、228 组 PDF 非零或非有限；修复后均为零且有限。
- 864 组 sample 覆盖四种反射/透射类型、diffuse/glossy/透明分支和边界随机值。
  基准 432 组无效观察输入及 12 组无效 GGX 出射样本未按终止/零密度契约处理；修复后全部满足。
  这里的失败数包括原来零 throughput 但未终止的样本，不能都说成能量泄漏。
- 有效域内保存的 1,014 条 eval/PDF、sample 权重/方向和 guide 结果与基准的 float32 文本逐条一致；
  普通有效样本的 throughput 与真实 eval/PDF 配套。无效观察输入的 432 组 RR guide 现在归零。
  单独确认 IOR=1 的正向/背向/掠射直通和发光终止保持原行为。
- `check-normal-map.py` 抽取真实 normal_from_sample/tangent_from_derivatives，复现上述
  Ns·V<0 输入、下述几何侧穿透和 UV 旋转差异；负非均匀缩放的 handedness 示例与零切线
  fallback 通过。这不是完整的烘焙、镜像资产、shear 或 GPU 导数验证。
- `just shader` 成功：31 编译、两个 binding crate 通过。Realtime/Offline raygen 通过
  `spirv-val --uniform-buffer-standard-layout`。只修改 shader 局部算法/契约，没有共享 ABI
  字段迁移，未重复完整应用构建；未进行 GPU 画面、能量积分或性能验证。

## 尚未闭合的设计项

**P1，B17-d/B27：几何侧与法线扰动模型。** Ns=(0.8,0,0.6)、V=Ng=(0,0,1) 是合法
着色观察输入，但镜面反射 L=(0.96,0,-0.28) 穿入几何背面，当前仍被接受。透射同样缺少
与介质侧配套的几何限制。本批未修改 faceforward；单纯改为按 Ns 或 Ng 翻面，不能同时保证
观察侧、几何侧、Snell、sample/eval/pdf 和能量正确。统一方案需明确法线扰动/裁剪策略、
反射/透射几何侧、transport 与能量处理，并让 RR 与实际模型保持一致。B19 先补齐 ReSTIR
key 的独立几何法线；当前 origin_normal=forward_normal 的重建不能用于证明真实几何侧约束。
最终模型修改仅给方案，不在本轮实施。

**P2，B17-d/B27：切线 UV/烘焙契约。** MaterialAccess 与 raster 共用世界 TBN，N 用
inverse transpose，T 用 model，sign 乘 determinant 符号。authored 分支保留原切线，缺失分支
用变换后 UV 的差分；平面 UV 旋转 90° 时，同一采样值分别产生 (0.8,0,0.6) 与 (0,-0.8,0.6)。
这是已复现的分支差异，尚不足以判定哪个匹配资产作者的目标约定。还需核对 UV override 下
authored tangent 的来源、选择烘焙/生成约定与参考资产；不以更换一处 cross 或固定翻转绿色通道
替代该决策。CPU 未生成 MikkTSpace，退化/极端数值和真实 GPU 纹理过滤仍需独立验证。

**P1，B17-d/B27：双面状态缺失。** glTF doubleSided 未进入当前材质状态，TLAS 仍 cull-disable；
Phong 使用 pipeline 默认 BACK cull。faceforward 不等于实现了源材质双面语义；后续方案须覆盖
导入、CPU/ABI、TLAS/raster cull、负缩放与背面 shading，而非只改 RT 光学一端。

**P2，B17-d：重复 payload。** Realtime/Offline 分别定义 RtSurfaceHit/MaterialType，通过
同一个 include guard 和 namespace remap 复用算法。首次编译准确暴露 Offline 缺少新增谓词；
已同步两份定义并重编译通过。后续收敛公共事件类型，保留 pass-local ABI/常量归各自 owner，
避免再复制字段或方法；本批没有夹带这一结构重组。
