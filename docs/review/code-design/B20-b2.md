## 修复与架构边界

旧 Resolve 在同一次 dispatch 中读取其它槽的 live hash/resolved，同时其它 invocation
可能淘汰或合并那些槽。B20-b1 的串行顺序反例结果分别为 8.4 与 2；前后 barrier 不能
为 dispatch 内的跨 invocation 读写提供稳定版本。

本批沿用现有 RT pipeline 的 phase 编排：Update→Snapshot→Resolve→主路径，每个
维护阶段后使用既有 RT read/write barrier。Snapshot 按 capacity 完整复制 hash/resolved，
包括空槽。Resolve 的当前槽、碰撞搜索、adjacent-level 查找均读取该快照；只写自己
entry 的 live hash、accumulation、resolved。未删除碰撞历史继承，未改变平均/淘汰公式。

SharcTargets 拥有两个新增 buffer，与原三个一同参与构造失败前缀回收和显式销毁；
初始化仍只清零三个 cache，快照在读取前完整覆盖，无须清零。regular set 4 增加 binding
3/4，descriptor pool 从 3 增为 5；创建时一次绑定，不按 FIF 更新，resize 保留。
push constant 仅新增 phase=3 常量，字段布局与 range 不变。无 Engine 能力、额外 queue、
CPU 跨帧索引或通用生命周期抽象。

代价：容量 2^22 时增加 96 MiB（总 buffer 大小由 160 到 256 MiB），每次维护额外
读取及写入各 96 MiB，并增加一次 TraceRays dispatch。Off 不维护。选择显式快照以保持
既有历史继承语义与稳定描述符；没有声称成本可忽略或已经完成 GPU 性能验收。

## 验证

临时材料位于 `.temp/code-design/B20-b2/`，未增加永久单元测试。

- `check-fixtures.py` 重用 B20-a 的实际 owner 抽取，扩展为五个 buffer、全部 32 种
  释放诊断 mask。五个分配位置 × allocation/叶子初始化失败 × mask 共 320 例，
  加上 32 组正常关闭，debug 开启 352 例、关闭 353 例通过。原始错误保留、无泄漏
  前缀与重复释放，五个 accessor/尺寸正确。额外例只记录未知 clear 未新增回收；
  mock 不证明实际未知提交可以安全 unwind，也不分配真实 256 MiB。
- 当前 ResolveEntry 的 960 组标量 oracle 通过；包含两个重复 key 对的 648 个顺序
  排列结果一致。原反例前后次序均为 8.4，保留旧样本继承。O0/O2 一致；CPU pack
  mock 不含 fp16 舍入或 GPU 撕裂，当前关闭的 adjacent-level 运行分支未做数值验收。
- `check-wiring.py` 抽取实际 Snapshot 函数，42 组 extent/模式含空槽、容量外哨兵，
  验证启用时完整覆盖且不改源；Off 不写。抽取实际 Rust 维护录制块，18 组 mode/
  capacity 确认 Update→barrier→Snapshot→barrier→Resolve→barrier，两个全表阶段
  extent 相同且覆盖 capacity，最后 phase=None。入口 barrier 仍覆盖下一帧复用。
- SPIR-V 反汇编确认五个 SHARC binding 均在 set 4，hash stride=8，packed stride=16，
  packed 字段 offset=0/8/12；push constant 全部 15 项 offset=0..56 保持不变，Rust
  生成绑定的 size=64/align=4/末尾 offset=56 编译期断言通过。快照复用既有 GPU-only
  元素类型，没有新增手写 CPU 镜像。
- `just shader` 24 编译、7 复用，两个 binding crate 通过；相关 Rust crate cargo check
  与 Realtime/Offline raygen SPIR-V 校验通过。既有 E41035 条件 candidate 告警保留。
- `check-sync.py` 从实际 barrier 提取 scope，使用 compute 代替 RT，模拟 live→snapshot
  复制与 snapshot→live 合并。在 RTX 4060 / API 1.4.351 / SDK 1.4.335.0，缺少复制后
  barrier 的初次/再次循环各报 WAR、RAW 两项；完整依赖零诊断并实际 submit/wait 完成。
  缺陷命令只录制后丢弃。启用局部 shader-access heuristic，不改变用户全局配置；
  此为同类读写链探针，不是完整 SHARC/TraceRays 或显存、性能、画面实测。
