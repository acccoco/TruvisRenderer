## 已确认问题与修改边界

**P1：只接受有效 winner 会丢弃零估计候选池。** `make_initial_reservoir` 仅在有效
winner 分支输出 M=1；`temporal_resample` / `spatial_resample` 又用 winner-only
`reservoir_reusable` 过滤来源。初始全零或复用后全零的池从后续 M/piSum 中消失，
使估计条件化到“至少采到一个正贡献候选”。原 finalize 的有限零结果也会清掉 M。

可复现反例：两个相同表面上的独立池各有八次 proposal，每次以 1/8 概率命中贡献 1、
PDF=1/8 的事件，其余为零。一个池命中 k 次，输出估计 k，正确期望为 1。旧 temporal
只对非零池取平均，期望为 `1+(7/8)^8=1.3436089158`；保留两个池的 M 后输出
`(k1+k2)/2`，期望为 1。此反例无需运动、Jacobian、动态可见性或极端浮点输入。

架构预检：修改归既有 RtReservoir / RtRestirDI，复用存储统计、版本、年龄和数值表示；
新增的 clear_sample 只管理本类型的 winner 状态。没有公共 API、持久化字段、descriptor、
CPU owner、线程、pass 顺序或资源生命周期变化。直接同步 sampling design，不更新 summary。

- initial 完成八次采样后无条件 M=1；不合格 surface 仍为 M=0。
- 增加 pool 接受判断，与 winner-only 着色判断分开。合法零池保存正 M、零 weight/target、
  无 winner/key；unpack 拒绝不一致标记、非法统计，不能将损坏数据解释成零估计。
- temporal/spatial 的竞争和校正使用同一 pool 集合。零池累加 M、不提供候选、不消耗
  竞争 RNG，但其 source surface 仍用于评估最终 winner 并累加校正分母。
- 有限零归一化清除 winner、保留 M；非法/不可表示的数值仍走既有失败边界，不能据此
  宣称该数值域无偏。initial 的失败输出在完成采样后同样记为一个零估计池。
- history cap 只限制上界，不把无候选池的 M=0 变成 1；空间采样的 8/16 次选择按池 M
  决定。零估计输出没有 sample identity，age 为零；有效 winner 的 age<=8 策略保持。

## 验证

临时证据位于 `.temp/code-design/B19-c2a/`，无永久测试。`check-pools.py` 抽取实际
RtLightSampleKey、RtReservoir、pack/unpack、initial、stream/combine/finalize、校正、
temporal/spatial 与 RNG；采样、surface、坐标/兼容性和 target 查询使用受控 mock。
spatial 仍执行实际两轮遍历；mock 邻居共享一类池，不能当成真实邻域独立采样实验。

| 检查 | 基准 → 修复后（O0/O2 一致） |
|---|---|
| 2,592 个两池 Bernoulli 组合，9×9 个命中数、16 seeds、temporal/spatial | 估计不符 512 → 0；M 不符 544 → 0；initial M 不符 544 → 0 |
| 对组合按二项概率求和 | temporal 期望 1.34360891581 → 1；spatial 1.34360891349 → 1.00000000026 |
| 10,368 个 absent/zero/winner、M、交叉 target、seed 和 phase 组合 | 估计不符 1,536 → 0；M 不符 5,616 → 0；winner 不符始终 0；最大相对误差 3.98e-8 |
| 152 项边界检查 | 全通过：age/version/cap、三种池的存储、非法标记/NaN/Inf、零归一化、未采样与跨阶段全零链 |

独立 double 参考按同一 RNG 顺序计算 raw sum、winner、接受池 M 与 pi/piSum。
全零链验证 temporal M=2、spatial M=34、下一帧 temporal M=3；这不代表增加有效光照样本。
修复前后比较说明的是计数和归一化错误，不能描述成旧代码选错了另一个有效 winner。

适配夹具的新增局部方法抽取后，B19-b 的 initial/finalize/combine/非法存储、16,384 个
混合数值组合与 65,536 seeds 分布检查全部通过；B19-c1 的 3,072 个年龄组合、18,432 个
数值归一化组合及 7 项非法/零项检查再次通过，O0/O2 一致。输入、参考和断言保持原样。
回归驱动第一次运行遇到 Python 文本替换误改导入字符串，修正驱动后年龄/归一化通过；
这是临时夹具生成错误，不是 shader 或数值检查失败。

`just shader` 完成 24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
均通过 `spirv-val --uniform-buffer-standard-layout`。未执行真实 GPU 图像、动态场景、
FTZ/subnormal 或性能验收，也不证明完整 estimator 无偏。
