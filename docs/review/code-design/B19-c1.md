## 发现与架构预检

**P1，已确认：** temporal 先对 age=8 的 history 调用 reusable，随后 age 增至 9，
combine 再按 age<=8 拒绝；history_m 和 result.M 却已经计入。若 initial/history target
均为 1、initial weight=1/M=1、history M=64，则保留的 initial 被归一化到 1/65。
修复应统一 source 接受、竞争、M 与校正集合，而不是放宽已定义的 age 上限。

**P1，已确认：** temporal/spatial 仍直接累加 target×M，即使 B19-b 的 raw sum 可表示，
校正分母可先变成 Inf，导致本应有限的结果被丢弃。需把此数值链补齐到 finalize 调用点。

局部修改归 RtRestirDI：history 先递增年龄，再统一核对 reusable；失效 source 不参与
竞争、M 或校正。新增 shader 局部 RtRestirNormalization，持有分母尾数/指数/有效性并负责
累加 target×M；finalize 前消去该指数，沿用 B19-b 的最终权重恢复。它只表达本轮校正状态，
不扩展通用数值库，也不持久化到图像。无 shared ABI、CPU owner、资源生命周期、线程、
pass 顺序或材质模型变更；同步 sampling design 和对应审阅交接。

参考 RTXDI 配置 v3.0.0，父仓库 `274141af082050c9d0ad6e01a2e591d0d66b7955`、
Rtxdi 子库 `a14e079c727ed8c4fd3173bd2aea8244c9d9f6d6`。`DI/TemporalResampling.hlsli`
和 `DI/SpatialResampling.hlsli` 的 pi/piSum 使用 source surface target 与 source.M；
本项目 age<=8 是自身策略，不宣称来自 RTXDI 的相同年龄上限。公式中的直接 float
乘加不证明完整数值范围，缩放仅调整本项目表示，保持公式。

## 验证与交接

年龄修复位于 `7979922e`。`check-age.py` 抽取真实 temporal_resample、capped
history、reusable、combine、stream/finalize 与 RNG；重投影与目标查询使用 mock，固定
current/history target=1，initial weight=2、history weight=4。age=0/7/8/9、M=1/8/64、
initial/history valid、history 开关与 32 seeds 共 3072 例，O0/O2 一致：权重/有效性不符
96 → 0，M 不符 192 → 0，修复后最大绝对误差 1.18e-7。没有样本 age 超过 8 的输出，
说明旧问题是计数与归一化偏差，不能错误描述成已输出 age=9 的有效 winner。

`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen 通过
`spirv-val --uniform-buffer-standard-layout`。证据在 `.temp/code-design/B19-c1/`；未执行
真实 GPU 图像、重投影或动态场景验收，夹具不证明完整 estimator 无偏。没有新增永久测试。

校正分母修复位于本报告所在提交。RtRestirNormalization 的 add 先分解 target/M，再
对齐指数并累加；非法输入保留 invalid 状态，不因后续正常项恢复。bias normalization
从 raw sum 的指数中减去分母指数，再交给原 finalize；numerator、winner 与来源集合不变。
只在 shader 局部增加状态，未改变 reservoir 图像布局或跨语言 binding。

`check-normalization.py` 抽取真实 temporal_resample、spatial_resample、normalization、
combine/stream/finalize。mock 坐标查询、兼容性与 target 查询：center/neighbor 两类 source，
仍执行实际 spatial 两轮遍历及动态 8/16 候选数。target 尺度 1e-30..3e38、邻域尺度比
.125/1/8（输入超出 float 的组合排除）、两侧 M=1/8/64、valid 组合与 16 seeds，共
18432 例；double 参考按同一 RNG 顺序独立计算 winner、raw sum、pi/piSum 和 M。
基准为年龄修复后的 `7979922e`：1867 个被错误清空的结果 → 0；修复后 winner/M 均与
参考一致，最大相对误差 4.25e-7（容差 3e-6），O0/O2 相同。另有 7 例非法/零项检查通过。
因此不能将这些错误清空计数描述成 raw 竞争阶段选错了另一个有效样本。
