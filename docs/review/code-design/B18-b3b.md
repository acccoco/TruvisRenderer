叉积、法线、面积、单面判定及 PDF；1e-11 m² 下限排除仍可表示的正面积，大尺度叉积长度

## 有限 analytic visibility

**P2：仅按方向投影截短 TMax，射线仍横向偏离采样目标。** 原 helper 将起点沿几何法线
推出，却保留原方向。除偏移正好与光源方向平行的情况外，这会改变遮挡路径；只减去
偏移的方向投影不能修复端点，尤其会错过原连接上的小遮挡物。

RtDirectLighting::make_visibility_ray 保留原接口，从 `light_dir*distance` 减去
起点偏移，再计算单位方向和实际长度；不先叠加大世界坐标。非有限长度、过短或正向投影
不为正的区间返回 TMax=0，既有 sphere/area 调用方拒绝空区间。analytic emitter 不在
TLAS，因此保留原目标而不套用 emissive triangle 的目标法线偏移。HDRI 分支不变，
BSDF/PDF 的原始连接不变；无 ABI、owner、线程、pass 顺序变化。

`.temp/code-design/B18-b3b/check-visibility.py` 抽取实际 helper，并核对夹具的
origin offset 与当前 ray_numeric 源码相同。基准 `76434dc8`，C++ O0/O2、关闭 contraction。
54 组覆盖原点 0/10/10000、距离 .01/1/100、三种法线与两种方向；按原目标相对坐标
计算 double 参照。5 组起点跨过目标，前后均为空；其余 49 组：

| 指标 | 基准 | 修复后 |
|---|---:|---:|
| 相对端点误差超过 2e-6 | 32 | 0 |
| 最大相对端点误差 | 25.000001 | 4.20e-7 |
| 预期连接中点的有限圆盘漏检 | 26 | 0 |
| 目标之后 1% 的平面错误命中 | 0 | 0 |

圆盘半径为原距离×1e-5，避免用必然相交的无限平面掩盖横向错位。另验证近原点
1e-5 距离的偏移跨目标对照被拒绝；54 组 HDRI origin、direction、TMin/TMax 均保持原值。
最大旧误差来自大世界坐标、短距离与侧向偏移；此处展示数值压力，不能视为实际场景频率。

再次 `just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen
SPIR-V 均通过同一验证参数。`git diff --check` 通过。没有 GPU tracing/图像回归，
CPU 圆盘相交夹具不能证明实际 TLAS、alpha-test、FTZ 或浮点 intrinsic 的完整行为。
