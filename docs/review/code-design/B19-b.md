# B19-b：initial RIS 与 reservoir 数值链

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准 `1d2645a9`，`refactor`，初始工作区干净。范围为 proposal→target→raw weight→
finalize→storage/final 消费的数值契约；temporal/spatial 的度量、支持域、校正来源归 B19-c。

## 发现

- **P1，已确认：** initial 使用 `1/max(pdf,1e-7)`，finalize 使用
  `max(selectedTarget*denominator,1e-7)`；低 proposal 或低 target 下改变 RIS 估计值。
  固定候选数仍应包含零 target/不可见 proposal，不能把 denominator 换成有效样本数。
- **P1，已确认：** raw target×inverse PDF、combine 三因子乘积、权重和、finalize 乘积
  可先于可表示的最终结果溢出；仅删除 floor 不闭合修复。当前 unpack 的正数比较接受 Inf，
  后续 valid 状态可能携带非有限权重。NaN 的比较也不能替代逐项 finite 检查。
- initial 的 M=1 是 finalized 输出供复用使用的约定，不是实际只抽一次；本轮固定抽取 8 次。
  target 为可见的同源 BRDF_cos×radiance×MIS 的 RGB 最大通道，既有 proposal 已含 class 概率。
  这里的标量不额外除 proposal；final shade 只乘 finalized inverse PDF。

参考配置 RTXDI v3.0.0，父仓库 `274141af082050c9d0ad6e01a2e591d0d66b7955`；
Rtxdi 子库 `a14e079c727ed8c4fd3173bd2aea8244c9d9f6d6` 与 gitlink 一致。
`Include/Rtxdi/DI/Reservoir.hlsli` 的 StreamSample、CombineDIReservoirs、FinalizeResampling
分别给出 target/pdf、target×sourceWeight×M、rawSum×numerator/(selectedTarget×denominator)。
参考代码的直接 float 乘积不是全数值域正确性的证明，本项目保留公式并调整局部计算表示。

## 架构预检与修复方案

复用 RtReservoir / RtRestirDI，增加仅 shader 局部使用的 raw 权重指数；竞争时用公共二进制
尺度累加，finalize 后恢复原有 float inverse PDF，指数归零。初始 PDF 直接进入比值分解，
避免先构造倒数；combine 复用同一竞争步骤。两处 floor 删除，落盘/消费检查有限合法统计。
存储 A/B/C/D 含义、共享 ABI、CPU owner、资源生命周期、线程与 phase 顺序均不变。
不新建通用数值库，不改 target 模型、复用邻域、history M cap 或校正公式。

Slang frexp/ldexp 的签名查阅官方 [frexp](https://shader-slang.org/stdlib-reference/global-decls/frexp)
与 [ldexp](https://shader-slang.org/stdlib-reference/global-decls/ldexp.html)；最终以本地配置的
Slang v2026.11 编译结果为准。[GLSL 指令规范](https://registry.khronos.org/SPIR-V/specs/unified1/GLSL.std.450.html)
不保证 subnormal/FTZ 行为，不能用 CPU 夹具推断 GPU 全范围保证。

## 验证与交接

修复位于本报告所在提交。initial 的 stream_sample 只接收实际 source PDF，删除未被其他
调用方使用的 sample_m/source_age 参数；initial 与 combine 共享 stream_weight 的 winner
更新和缩放累加。RtReservoir 的 weight_exponent 仅在 shader 局部存活，finalize 后归零，
load 从零初始化；原有 storage layout 不变。unpack/reusable 拒绝非有限统计与 sample 参数；
target contribution 拒绝非有限/负 RGB，final shade 拒绝非法权重和最终 RGB 溢出。

`.temp/code-design/B19-b/check-reservoir.py` 抽取真实 RtReservoir、initial、stream、combine、
finalize、unpack/reusable 与 LCG/rnd。候选与 target 用受控输入，未执行真实 BRDF、visibility
或 GPU image；以 double 公式对照，有限正常范围的相对误差容差 2e-6。

| 夹具 | 覆盖 | 修复前 → 修复后 |
|---|---|---|
| initial 168 例 | PDF 1e-30..1e30、target 1e-30..1e30；8 次中 1/4/8 个非零项 | 不符 108 → 0；仍固定除以 8、输出 M=1 |
| finalize 501 例 | 四因子交叉组合；包括中间溢出但最终有限、以及最终超出 float 上限 | 不符 306 → 0；不测试最终 subnormal 保证 |
| combine 27 例 | 两个 source，target/weight 各三种尺度、M=1/8/64 | 不符 12 → 0；M 累加与公式保持 |
| storage 15 例 | 权重、target、M、age、sample 参数的负数/Inf/NaN；负 sample 坐标允许 | 错误接受 8 → 0 |
| mixed 16384 例 | 8 个不同 proposal/target，16 组全局尺度×1024 seeds，真实 LCG | 权重不符 12288 → 0；与 double 竞争选择不符 3704 → 0 |
| 非零权重 1:3 | 65536 seeds；其余六个 proposal 为零 | 两版均选第二项 49152 次，均值 .5，原有正常域结果保留 |

上述 O0/O2 结果相同，修复后的最大相对误差 1.23e-7。`check-consumer.py` 另抽取真实
target contribution/final shade，mock BRDF：17 例有限/非法权重、各 RGB 通道 Inf/NaN/负数
与最终乘积溢出，错误 12 → 0；O0/O2 一致。有限 RGB 最大相对误差 2.20e-8。

`just shader` 通过：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen 通过
`spirv-val --uniform-buffer-standard-layout`。反汇编存在 Frexp/Ldexp，未引入 Float64
capability。没有修改 Rust 或共享 ABI，未重复完整 App/GPU 构建。没有新增永久测试。

**验证边界：** 没有真实 GPU 画面、FTZ/subnormal、性能或端到端 estimator 验收。
缩放尾数仍有 float 舍入；指数差超过 126 的项在本轮置零，不能声称任意动态范围下保持
精确选择概率。24-bit RNG 也不能表达任意小概率。最终权重/RGB 不可表示时返回空结果，
不把它描述成无偏修复。target 生产中 radiance×BRDF×MIS 的完整 HDR 支持域也未证明。
