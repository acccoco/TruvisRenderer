## 修复一：MIS 权重的公共尺度

**P1：epsilon 改变互补权重，大 PDF 平方溢出。** 原 power heuristic 为
a²/max(a²+b²,1e-7)。a=b=1e-5 时各自权重约 0.001，总和约 0.002；a=b=1e20 则可能
发生 ∞/∞。PDF 是密度，合法值可以大于 1，也可以很小，不能通过固定分母下限修补。

现先用 max(a,b) 归一化，保留相同平方比值；有限、非负输入至少一项非零时，归一化分母
位于 [1,2]，无需 epsilon。(0,0) 定义为零。删除全仓没有调用者的 balance 和可变 beta
变体，保留现有唯一使用的 power heuristic，不增加平行公式或 fallback。

参考本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（resources.toml 配置 master），
`src/pbrt/util/sampling.h::PowerHeuristic`。项目各策略按一次样本使用完整 PDF；采用同一
数学比值，但用公共尺度归一化代替参考的单侧平方溢出处理。ReSTIR 多候选权重组合另属 B19，
不能因它调用此函数就套用“两个独立单样本估计器已验证”的结论。

`.temp/code-design/B18-a/check-mis.py` 抽取真实函数，在 C++ float O0/O2、禁用 contraction
下与 double 比值对照；覆盖零、subnormal、最小 normal、常用值及最大有限值共 196 对。

| 指标 | 基准 | 修改后 |
|---|---:|---:|
| 非有限权重 | 42 | 0 |
| 权重误差超过 1e-7 | 69 | 0 |
| 非零配对之和不符合 1 | 123 | 0 |
| 最大有限绝对误差 | 1 | 4.64e-8 |

另以两区间概率分布构造解析积分：A 均匀，B 的两区间概率为 1/4、3/4；积分目标为 1。
在区间总长 1e-20 至 1e30 的七种尺度下，原实现五组失败，修改后全部误差小于 1e-7。
这只隔离 MIS 权重，未执行实际 shader 的 PDF clamp、visibility、reservoir 或 GPU。
`just shader`：29 编译、2 复用、两个 binding crate 通过；Realtime/Offline raygen 通过
`spirv-val --uniform-buffer-standard-layout`。未更改共享 ABI，未重复完整应用构建。

## 修复二：发光命中 PDF 的覆盖域

**P1：普通材质的 emission 被 NEE 与路径命中重复计入。** CPU is_emissive_material 依据
emissive_factor + class.emissive_radiance，不限于纯 EMISSIVE；几何记录保留 primitive 顺序，
base map 表达是否属于光源表。主 path 与 SHARC 都会为普通材质累加 emission，但
emissive_hit_pdf 首先拒绝所有非 EMISSIVE 类型，从而误报竞争 light PDF=0。
当 NEE 的配对权重非零时，路径侧仍取完整权重 1；两者不再互补。

现由真实 surface 与光源 base map/record 判断可采样性，不再用光学类别代替光源表。
保留无记录 sentinel、geometry 范围、record identity、零 area/select_pdf 与关闭 NEE 的拒绝路径。
class 选择概率仍只在 unified 层乘一次；camera/delta 链原有跳过 MIS 的策略不变。

`check-emission.py` 抽取实际 emissive hit/unified PDF、面积换算与 Mis，使用 mock instance、
base map 和 record 承载查询数据，C++ float O0/O2 禁用 contraction。240 组覆盖五种命中
材质类别、距离、面积、余弦、选择概率和两种 class 数量；基准 192 组错误返回零，修复后
全部匹配独立 double 公式。在相同几何端点下使用 NEE/hit 两侧完整 PDF，配对 MIS 权重
也全部互补。七类零返回对照覆盖 sentinel、geometry 范围、identity、零选择概率/面积、
关闭 NEE 与 NO_HIT。未运行真实 GPU table 上传、纹理采样或射线偏移后的几何闭环。
第二次 `just shader`：24 编译、7 复用、两个 binding crate 通过；Realtime/Offline raygen
通过 `spirv-val --uniform-buffer-standard-layout`。未做 GPU 画面、方差、性能或 FTZ 验证。

## 已核对与后续边界

- NEE candidate 的完整 PDF 为 class_pdf×条件密度；unified_hdri_pdf 和
  unified_emissive_hit_pdf 使用相同 class_count。普通 NEE、path miss/emission、ReSTIR
  target 和 SHARC 消费同一个 Mis；analytic v1 没有 BRDF-hit 竞争，仍固定 MIS=1。
- **B18-b1：** EnvMap 的 distribution/alias、返回方向重新查询 PDF、零概率与采样覆盖
  尚未完整验证，不能从 class 因子相同推出条件分布正确。
- **B18-b2/b3：** emissive/area 的 distance²/cos 换算可能溢出；密度生产端只检查正值
  不等于保证有限。MIS 的前置是有限非负输入，本批没有掩盖 NaN/Inf 生产错误。
  hit_t 来自偏移后 ray 起点，NEE distance 来自原 surface，几何端点/PDF 一致性也须继续核对。
- **B18-c：** shade_candidate 与 sample_diffuse 的 PDF 分母仍有 1e-7 clamp；它与 MIS
  分母不是同一处。本批配对权重正确不证明实际积分贡献无偏，需连同合法域/终止策略复核。
  继续承接 B17-d 的 roulette 返回字段冗余及纯发光 reflection-distance 近似查询。
- **B19/B20/B27：** reservoir/cache 算法与归一化、GPU subnormal/FTZ、极端光源/材质输入
  支持域和画面验收未完成。B17 的层能量、复合 lobe、法线和 radiance 溢出提案保持有效。
