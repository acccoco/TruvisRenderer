## 已确认的局部问题

- **P1：完成结果在诊断或消费失败时失去 owner。** poll 的局部 Vec 在 staging 日志异常时
  丢失已完成目标；texture 发布失败会销毁同批次迭代器，连尚未交给 sky 的结果也丢失。
  改由上传 queue 保存 typed VecDeque，consumer 借用并逐项 pop。poll 先保存目标，再回收
  staging；诊断失败延后传播，未移交资源继续留在 queue。stale/duplicate 拒绝先释放 native，
  再输出附加诊断。shutdown 在等待完成后收尾 pending、未消费结果、semaphore/pool，再传播
  首个日志异常；等待失败仍保持 B10-a1 的 owner 契约。
- **P1：texture 安装失败没有撤销登记。** view 创建或 bindless 容量失败时，registry 已拥有
  image，texture cache 尚无记录；再次 prepare 可重复上传并积累孤立资源。由本批第二项修复。

第二项让普通 texture 与 fallback 共用 register_texture_binding：先登记已完成的 image，
安装 view/SRV 成功才交付 binding；失败撤销已登记 SRV，并立即回收尚未发布的 image/view。
registry 完成 native 回收后产生的日志异常不覆盖安装原始错误。已发布资源的删除仍先
unregister SRV、再按 current frame 退役，不提前释放。texture store 关闭逐项收尾全部
已发布 binding 和 fallback 后再传播诊断异常；调用方仍须保证 GPU 已不再使用。

完成存储只承载尚未移交的 owned GPU 资源，不新增第二份 CPU 权威状态或任务调度器。
资源仍由 RenderThread 操作；成功上传不等于已发布，发布成功也不证明所有消费者同步正确。

## Texture 安装与引用验证

`run_texture.py` 编译 `4362577c` 与当前 GpuTextureStore 全文以及实际 TextureResolver 定义，
使用锁定的真实 SlotMap/SecondaryMap 检查 generation。仅 RHI、registry/bindless 操作和
SceneReadView/提交服务用受控替身替代；不把替身的释放计数当作真实驱动结果。

断言/溢出检查同开、同关时各 15 类新旧对照通过：fallback 和普通上传的 view/bindless/query
失败、rollback 中 registry 日志失败、批量关闭日志失败、正常发布、Loading/Ready 去重、提交
Err 重试、上传中删除、已发布删除后 generation 复用、重复完成及 stale 释放诊断失败。
旧版安装失败遗留 registry image/view 或 SRV；新版撤销本次登记，保留其余完成项，重试后
无累积孤立对象。失败/未 ready resolver 仍返回 fallback，发布后 revision 从 0 到 1；
旧 generation 不复活，新 generation 独立发布。已发布删除验证了退役登记帧，未模拟真实 FIF。

`cargo check --offline --locked -p truvis-render-runtime`、
`cargo check --offline --locked -p truvis-app` 与 `git diff --check` 通过。
没有新增仓库单元测试或运行真实 GPU。

## 跨 queue 验证交接

当前 GfxCore 分配同一 graphics family 的 index 0/1 分别作 graphics/transfer queue。
本批没有证明消费者 wait/可见性链；host counter 查询只作为本地完成观察依据。
[Vulkan 同步规范](https://docs.vulkan.org/spec/latest/chapters/synchronization.html) 将 queue
semaphore wait 与 memory dependency 联系起来；[counter 查询接口](https://docs.vulkan.org/refpages/latest/refpages/source/vkGetSemaphoreCounterValue.html)
描述的是 host 查询。来源核对日期 2026-10-29。跨 queue 闭环交独立 B10-e，需结合 mesh/sky
所有上传队列和 graphics 提交入口核对，不能从本批 CPU 夹具推断已满足。
