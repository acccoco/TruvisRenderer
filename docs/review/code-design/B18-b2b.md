## CPU 面积与法线

**P1：** f32 cross.length() 的中间平方范围比面积窄。边长 1e-12 的三角形被误判为零，
边长 1e10 的三角形面积为 Inf，尽管 5e19 可由 f32 表示；世界法线随后也可能归一化为零/NaN。
仅修复 world area 不够，因为 metadata 的零 local_area 会先挡住经 instance 放大的三角形。

现由 RtTriangleMeta::area_vector 统一计算 f64 面积向量，先扩展顶点再相减；local_area
改为 f64，世界面积和归一化中间量也使用 f64。仅写 GPU record 时收窄到 f32，不能表示的
面积保留零权重记录；不压缩 primitive，不增加 GPU ABI 类型或平行表。退化 local gate 保留，
避免变换舍入使局部退化三角形产生虚假权重。未引入新的资源 owner、线程或上传路径。

公式参考本地 PBRT `b4ce9687e6c695f5582997c61b0c66cf064bdb4a`（配置 master）
`shapes.h::Triangle::Area` 的半叉积长度；项目仅将 CPU 运算扩展到 f64，不移植其 shape 框架。

`.temp/code-design/B18-b2b/check-table.py` 抽取真实 metadata、append_submesh_triangles、
area_vector、luminance 与 build_alias_table。mock material/instance/record 容器，链接本次
`cargo build -p truvis-render-runtime --message-format=json` 返回的 glam 0.22.0 rlib；
Rust O0/O2。最初误选带 glam-assert 的旧 rlib，基准 normalize 因非有限结果 panic，随后改用
构建实际依赖重跑，不能将该 panic 当作本配置的确定运行行为。

36 组三角形组含两个反绕序非退化三角形和中间一个退化 primitive，覆盖六种边长
1e-20 至 1e19、三种缩放 1e-10/1/1e10、负缩放与非均匀缩放，共检查 72 个非退化源记录。
独立 XY 行列式作为世界面积/绕序基准；超出 f32 面积范围按零权重契约检查。

## Shader 面积到立体角 PDF

**P1：** 先计算 select_pdf/area，再乘 distance 两次，可能在最终值仍可表示时提前
溢出/下溢。现用 s=distance*sqrt(select_pdf)/sqrt(area)，pdf=s*(s/light_cos)；保持
相同正数公式，先在较温和的尺度组合离散概率、距离和面积。实际 candidate/hit 调用方均有
distance guard，输入仍是原始表面连接；未增加第二套 PDF，也未使用 GPU double。

共同函数拒绝非有限输入和最终密度，确保 emissive NEE、ReSTIR 重建与 hit 竞争查询都
返回零，不将 Inf/NaN 交给 Mis。保留现有 light_cos<=1e-6 拒绝域，不对剩余候选重归一化。
参考上述 PBRT commit 的 `shapes.h::Triangle::Sample/PDF` 面积分支：相同 Jacobian，
sample 与 PDF 都拒绝 Inf；项目仍是统一面积 proposal，不引入它的 spherical triangle 分支。
平方根尺度重排是本项目的数值适配，不能归称 PBRT 原样实现。

`check-pdf.py` 抽取实际共同函数，mock light，C++ float O0/O2、关闭 contraction；
8 个 area（含最小 subnormal 至 3e38）、6 个 select_pdf、6 个 distance（1e-6 至 1e18）、
4 个 light_cos，共 1152 组，与 double 的乘积/商对照。其中 740 组预期为 normal f32：

| 指标 | 基准 | 修复后 |
|---|---:|---:|
| 非有限或相对误差超过 8e-7 | 92 | 0 |
| 非有限输出 | 16 | 0 |
| 错误返回零 | 39 | 0 |
| 最大有限相对误差 | 1 | 2.45e-7 |

146 组超出 f32 最大值的最终密度在修复后全部返回零。另检查 area/select/distance 的
零、负数、Inf/NaN，法线 NaN，以及掠射阈值本身和紧邻其上的 float。小于 normal 范围的
其它组合没有被计入上述精度通过数，不能宣称 subnormal/FTZ 全部正确。
这些是公式隔离夹具，不证明完整 sampler、光照积分或 GPU 内建 sqrt 的逐位结果。

`just shader`：24 编译、7 复用，两 binding crate 通过；Realtime/Offline raygen 的
SPIR-V 通过 `spirv-val --uniform-buffer-standard-layout`。未执行 GPU 图像、方差、性能、
完整应用启动或 BLAS 验证，平方根开销与 CPU f64 元数据的成本也未 profiling。
