# B06-b：Bindless 与全局 binding owner

> 历史说明：本文项目 hash、提交次数及“本报告所在提交”均按压缩前历史解释，实验引用保留为“压缩前证据基准”；第三方版本不变。当前分组见[提交压缩映射](commit-squash.md)。


基准：`refactor` 的 `eb01e674`，工作区干净。读取 BindlessManager、ShaderBindingSystem、
GlobalDescriptorSets、RenderSamplerManager、descriptor_bindings；追踪 Runtime begin_frame/
prepare 和 texture/sky 的 register/unregister，复核 descriptor pool/layout/set、sampler leaf。

## 已确认问题与局部方案

- **P1，到期 slot 归还晚于本帧注册。** begin_frame 只更新帧号；prepare_render_data 才归还退役
  slot，而 texture completion 安装发生在 prepare_render_data 之前。满表时即使旧 slot 已过 FIF
  安全点，新纹理注册仍直接 panic。把到期 slot 回收移到已完成 timeline wait 的 begin_frame，
  prepare 只写新增条目；不缩短退役窗口，不新增 descriptor set 或动态扩容策略。
- **P1，null 注册仅 debug 断言。** 无断言时可能先消耗 free slot，再因无效 key 失去逆向映射，
  污染 dirty/slot 状态。入口使用常驻断言；shader index 的 usize/i32 转换拒绝溢出和 null。
- **P1，组合构造失败遗失 owner。** GlobalDescriptorSets 的 layout 创建后 set 分配失败、
  sampler 数组中途失败、descriptor write 失败，以及 ShaderBindingSystem 的下游构造失败，
  均缺少上层显式回收。使用局部 Option owner 和既有 destroy 方法分阶段交付；不靠 Drop 销毁。

## 架构与同步边界

修复留在现有 bindings owner/impl，不新增全局异常框架、free helper、线程或依赖方向。
Runtime begin_frame 已在 registry cleanup 前等待 current_frame_id-FIF，随后调用 binding begin_frame；
注册前回收沿用同一完成条件。live slot 不原地替换，unregister 后至少跨 FIF 才可复用。
shader ABI、1024 个 sampled-image 描述符、每个 FIF 的 set 2 和静态 sampler 表均保持不变。

单套 bindless set 使用 PARTIALLY_BOUND/UPDATE_AFTER_BIND/UPDATE_UNUSED_WHILE_PENDING；
这些标志不能允许覆盖仍被 shader 动态访问的 slot。依据：
[VkDescriptorBindingFlagBits](https://docs.vulkan.org/refpages/latest/refpages/source/VkDescriptorBindingFlagBits.html)。
registry 回收 view 与 slot 归还使用相同退役帧前提；未使用条目不要求写 null descriptor。
material/scene 对旧 slot 的最终引用撤销仍需 B08–B11 的消费链证据，不能仅靠帧号宣称整体同步正确。

局部构造回收仅覆盖尚未发布/提交的新资源；正常销毁要求 GPU 不再使用 descriptor/sampler。
同步 Runtime README 与批次交接，不更新 summary，也不改变设备扩展/feature 基线。

## Slot 验证

`.temp/code-design/B06-b/make_slot.py/run_slot.py` 编译实际 BindlessManager、FrameLabel、
handle 和生成 shader SRV 类型，使用真实 SlotMap；registry/native descriptor 写入与 cursor
采用替身，capacity 与当前 descriptor 声明核对为 1024。新旧版在断言开关下各运行 14 组，
新版全部通过：满表到期/未到期、live dirty、取消后回收、未来帧、重注册、重复注册、null
注册/注销/查询、write 失败重试、stale view、shader index 溢出与 null index。

旧版 full-reclaim 在 frame 13 仍无空闲 slot；无断言 null 注册会污染状态。新版在 begin_frame
归还到期 slot，未到期的仍保留；dirty 在成功写入后才移除。`cargo check --offline --locked
-p truvis-render-runtime` 通过。没有真实 GPU/validation layer 验收。

Slot 修复对应 `6abaf441`；组合构造回收与交接位于本报告所在提交。

## 组合构造修复与验证

GlobalDescriptorSets 先保存可空的 layout owner，set 分配失败时销毁 pool 及已创建 layouts。
RenderSamplerManager 以固定长度 Option 数组记录逐项构造，全部创建和 descriptor 写入成功后
才转换为完整数组；既有 sampler 配置计算保持原位，没有新增通用构造器或并行表。
ShaderBindingSystem 先建立 CPU-only bindless，再创建 native owners；下游失败显式回收 global
descriptors。移除 BindlessManager 的无资源 Drop 日志，避免在错误退出时引入额外 logger panic。

删除无调用点、必然 panic 的 GlobalDescriptorSets::default；显式 context 是唯一构造入口。
静态 sampler 表在分配前检查没有未赋值条目，防止未来枚举扩充时静默采用默认 sampler。

`.temp/code-design/B06-b/make_owner.py/run_owner.py` 编译上述四个实际模块、FrameLabel 与生成
shader 常量；native pool/layout/set/sampler/cursor 使用事件桩，set 的分配由 pool 统一计入释放。
以 `6abaf441` 为基准，新旧版在断言开关下各运行 37 组，新版全部通过：成功、CPU bindless
初始化、pool、三个 layout、五个 set、25 个 sampler 逐项失败及 descriptor write 失败。
新版无遗留 native owner，旧版可观察未释放对象；替身 Drop 只记录遗留，不模拟真实 debug
二次 panic/abort。成功时新旧 25 项 sampler 的名称/全部描述字段一致，pool 容量与 set 数未变。

该夹具不执行 Vulkan，不能证明真实驱动的分配/写入、硬件 limits 或 shader 动态访问符合要求。
leaf naming/native 回收沿用 B05 验证；宿主分配 abort、native destroy 异常与更外层 Runtime
退出不作恢复保证。没有新增单元测试或修改 shader ABI。

最终 `cargo build --offline --locked -p truvis-render-runtime`、
`cargo check --offline --locked -p truvis-renderer` 与提交前空白检查通过。

## 结论与交接

registry 分离；只读 ShaderBindingView 服务 render/pass 的能力限制，有明确用途。
dirty map 通过 slot 的 Some/None 区分写入/退役，当前没有必要再建平行 pending registry。
